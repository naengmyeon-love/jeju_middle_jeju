# 퐁당패밀리 공식 가이드라인 자동 주입기

## 역할
퐁당패밀리 IP 의 **공식 가이드라인**을 생성 파이프라인의 모든 단계에 자동으로 주입한다. 가이드가 누락된 상태에서는 결과물을 생성하지 않도록 강제한다.

## 핵심 원칙

1. **공식 원본 우선**: `../../shared/references/WORKFLOW_GUIDE.md`와 관련 원본 페이지를 실제로 확인한 뒤 `../../shared/guides/character-guide.md`, `.json`, `character-guide` skill을 구조화 컨텍스트로 사용한다.
2. **강제 주입**: 기획안·시나리오·스토리보드·영상 생성 전, 해당 단계의 시스템 프롬프트에 가이드라인이 반드시 포함되어야 한다.
3. **검증 가능성**: 가이드가 주입되었음을 확인할 수 있는 메타데이터(버전, 적용 일시)를 결과물에 기록한다.

## 가이드라인 카테고리

### 캐릭터 정보

**출처 우선순위: 공식 PDF/페이지 PNG → 구조화 MD/JSON → `character-guide` skill.**

주입 시 각 캐릭터에 대해 다음 필드를 `character-guide`에서 그대로 인용한다. **예시를 창작하지 않는다.**

| 필드 | character-guide 참조 위치 |
|---|---|
| 캐릭터 이름 (한글/영문) | §4 각 절 제목 |
| 정체성 (종족·모티브·신분) | §4 각 절 "정체성" |
| 프로필 (MBTI·좋아함·싫어함·장점·단점·취미·특기·특징) | §4 각 절 "프로필" 표 |
| 말투·어미 | §4 각 절 "말투" + §7 말투표 |
| 외형 O/X 규칙 | §4 각 절 "외형 O/X 규칙" |
| 관계 설정 (극성 포함) | §5.1 관계표 |
| 금지 행동 | §4 각 절 "금지" |
| 키 순서 | §3.1 키 비례표 |

**공식 6인 (이 외의 캐릭터는 생성 금지):**
부라봉(BOO RABONG) · 고르방(GO LEBANG) · 양퐁당(YANG PONGDANG) · 냥냥이(NYANG NYANGI) · 호꼬(HOKKO) · 구애구(GU AEGU)

**주입 시 반드시 포함해야 하는 절대 규칙 (오류 빈발 항목):**

| 규칙 | 내용 |
|---|---|
| 양퐁당 | **해녀가 아님.** 해녀복을 입은 **토끼 취준생**. 물질·잠수 금지, 수영 못함 |
| 호꼬 | **말을 못함.** 대사 부여 금지 |
| 부라봉 | **기억상실.** 과거를 확정하는 서술 금지 |
| 무대 | **고르방의 집**이 주 무대. 귤밭은 구애구가 지키는 할머니의 별도 장소 |
| 관계 | 공식 **부정** 관계(호꼬↔냥냥이, 호꼬→양퐁당, 구애구→냥냥이)를 미화 금지 |
| 키 순서 | 고르방 > 양퐁당 > 부라봉 > 구애구 > 냥냥이 > 호꼬 |

### 브랜드·디자인 규칙

| 규칙 | 내용 |
|---|---|
| 공식 색상 | ⚠️ **공식 HEX 팔레트 미확보** (`character-guide` §9-1). HEX 값을 임의 생성하지 말고, 색상은 서술형(예: "주황 한라봉 몸체, 초록 꼭지")으로만 지시한다 |
| 로고 사용 | ⚠️ **로고 사용 규정 미확보** (`character-guide` §9-2). 공식 로고 파일만 사용하되, 규정 확정 전까지 로고 삽입은 담당자 확인 대상으로 표시한다 |
| 배경·소품 | 고르방의 집 / 할머니의 귤밭 / 제주 자연을 기본으로 한다. 공식 배경 설정집은 미확보(`character-guide` §9-9)이므로 신규 배경은 담당자 확인 대상으로 표시 |
| 세계관 설정 | 공식 설정 외 세계관 임의 확장 금지, 승인된 범위 내에서만 확장 |

### 콘텐츠 제한

| 제한 항목 | 내용 |
|---|---|
| 상업적 표현 | 직접적 구매 유도, 가격·할인 언급, 링크 클릭 유도 문구 금지 |
| 부적절 표현 | 폭력적·선정적·혐오적·정치적·종교적 표현 금지 |
| 타인 IP | 타사 상표·캐릭터·음악·이미지 무단 사용 금지 |
| 저작권 | 확인되지 않은 음원·폰트·이미지·음성 사용 금지 |

### 보안 규칙

| 항목 | 내용 |
|---|---|
| 가이드 원본 열람 | 공식 캐릭터 가이드 원본(PDF)은 권한이 있는 사용자만 열람한다 |
| 외부 전송 데이터 | 외부 AI 서비스로 전송되는 데이터 범위를 사전에 확인한다. 미공개 캐릭터 설정·내부 자료는 전송하지 않는다 |
| API 키 | API 키는 코드나 문서에 직접 작성하지 않고 환경변수로 관리한다 |

## 작동 방식

### 1단계: 가이드 데이터 로드

`guide-injector`가 호출되면 다음 절차를 따른다:

```
1. `../../shared/references/WORKFLOW_GUIDE.md`를 Read 한다.
2. 관련 캐릭터의 소개·턴어라운드·사용 규칙 페이지 PNG를 실제로 확인한다.
3. `../../shared/guides/character-guide.md`, `.json`과 `character-guide/SKILL.md`를 Read 한다.
4. 파일을 읽지 못한 경우
   → "공식 가이드(character-guide)를 읽을 수 없습니다. 결과물을 생성할 수 없습니다." 오류 반환 후 중단
5. 구조화 가이드의 버전을 추출해 기록한다.
6. 등장 캐릭터에 해당하는 §4 절 + §3 공통 비주얼 + §5 관계 + §6 톤앤매너 + §7 고정 프롬프트를 추출한다.
7. 추출 시 [공식] / [구조화] / [운영] / [확인필요] 라벨을 함께 보존한다.
   - [확인필요] 항목은 "담당자 확인 필요"로 표시하고, 값을 임의로 채우지 않는다.
6. 추출 데이터를 시스템 프롬프트용 텍스트로 직렬화한다.
```

> **금지**: character-guide 에 없는 캐릭터 정보를 기억·추측으로 보완하지 않는다.
> 정보가 없으면 `담당자 확인 필요`로 표시한다.

### 2단계: 단계별 주입 포맷

**기획안 단계에 주입할 프롬프트:**

```
[퐁당패밀리 공식 가이드라인 — 기획안 단계]

■ 등장 캐릭터:
{캐릭터별 공식 외형, 성격, 말투, 관계}

■ 허용 행동: {허용 행동 목록}
■ 금지 행동: {금지 행동 목록}
■ 공식 색상: {색상 목록}
■ 세계관: {세계관 설정}

■ 콘텐츠 제한:
- 직접적인 상품 판매·구매 유도 금지
- 가격·할인·홍보 문구 금지
- 폭력적·선정적·혐오적·정치적·종교적 표현 금지
- 타사 IP 무단 사용 금지
- 저작권 미확인 음원·폰트·이미지·음성 사용 금지

■ 검수 시 확인 사항:
- 캐릭터 외형·성격·말투가 공식 가이드와 일치하는가
- 60초 미만 구현이 가능한가
- 상업적 메시지가 없는가
```

**시나리오 단계에 주입할 프롬프트:**

```
[퐁당패밀리 공식 가이드라인 — 시나리오 단계]

(기획안 단계의 가이드 + 추가)
■ 장면별 캐릭터 행동 규칙:
- 캐릭터는 공식 가이드에 명시된 신체 특징·색상을 유지해야 함
- 장면마다 다른 캐릭터의 특징이 혼합되지 않아야 함
- 캐릭터 간 관계는 설정과 일치해야 함
- 대사 어미는 공식 말투와 일치해야 함

■ 기술 규칙:
- 모든 장면은 60초 미만 총 길이에 맞춰 시간 배분
- 장면 간 인과관계 자연스러워야 함
- 갑작스러운 설정 변경 금지
```

**스토리보드 단계에 주입할 프롬프트:**

```
[퐁당패밀리 공식 가이드라인 — 스토리보드 단계]

(이전 단계의 가이드 + 추가)
■ 연출 규칙:
- 캐릭터 외형 프롬프트는 공식 가이드와 1:1 대응
- 색상은 character-guide 의 서술형 표기를 그대로 사용 (공식 HEX 미확보 — 임의 생성 금지)
- 배경·소품은 공식 설정 내 항목만 사용
- 각 장면 이미지는 공식 소개·턴어라운드·사용 규칙 페이지를 실제 참조 이미지로 제공해 생성
- 이미지 안에 대사·자막을 굽지 않고 Markdown에서 이미지와 텍스트를 함께 제시
- 생성된 장면 이미지를 다시 열어 캐릭터 외형·장면 일치·연속성을 확인
- 자막은 화면 밖으로 잘리지 않게 배치
- 대사와 입 모양/장면 타이밍이 크게 어긋나지 않게 구성

■ 3안 연출 방향:
- A안(기본형): 안정적, 정보 명확
- B안(코미디형): 표정·타이밍·반전 강조
- C안(감성형): 관계·세계관 강조
```

**영상 생성 단계에 주입할 프롬프트:**

```
[퐁당패밀리 공식 가이드라인 — 영상 생성 단계]

(스토리보드 단계의 가이드 + 추가)
■ 영상 기술 규칙:
- 최종 영상 형식: MP4
- 영상 길이: 60초 미만
- 화면 비율: 9:16 (기본)
- 해상도: 1080×1920 (기본)
- 자막은 화면 내 가독성 보장
- 대사와 입 모양/장면 타이밍 일치도 확인
```

### 3단계: 가이드 버전 및 적용 이력 기록

가이드가 주입될 때마다 다음 정보를 결과물에 기록한다:
- 가이드 버전 (character-guide SKILL.md 제목에서 추출, 예: `v2.0`)
- 적용 일시 (ISO 8601)
- 적용된 카테고리 (캐릭터/브랜드/제한/기술)
- 적용 대상 (기획안/시나리오/스토리보드/영상)
- 실제 확인한 원본 페이지 번호

## 예외 처리

| 상황 | 처리 |
|---|---|
| character-guide 읽기 실패 | 결과물 생성 중단, 경로 확인 요청 |
| [확인필요] 항목 요구됨 | 값을 창작하지 않고 "담당자 확인 필요"로 표기 후 진행 |
| 가이드와 입력 충돌 | 공식 가이드 우선, 충돌 사항을 수정 제안으로 기록 |
| 새 캐릭터 등장 | 공식 6인 외 캐릭터는 생성하지 않음, 가이드 업데이트 요청 |
| 가이드 버전 변경 | 변경 내역을 제작 이력에 기록 |

## 산출물

가이드 자체는 별도 파일로 관리되며, 주입 결과는 각 단계 결과물의 메타데이터에 기록된다:
- `project-output/metadata/production-log.json` 내 `guide_applied` 필드
