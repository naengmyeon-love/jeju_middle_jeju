# 스토리보드 B — 비자림 숲길 산책 (비자나무 감탄)

> 기획안 B 기반: 거대한 비자나무를 발견한 부라봉의 순수한 감탄과 코믹 비교

---

## 기본 정보

| 항목 | 내용 |
|---|---|
| 제목 | 비자림 숲길 산책 — 부라봉의 비자나무 감탄 |
| 길이 | 15초 |
| 비율 | 9:16 (세로형) |
| 캐릭터 | 부라봉 (단일) |
| 배경 | 제주 비자림 숲길, 수백 년 된 비자나무 |

---

## 장면별 구성

### 장면 1 — 비자림 산책 (0-3초)

| 요소 | 내용 |
|---|---|
| 화면 | 비자림 숲길. 부라봉이 프레임 아래에서 등장해 천천히 걷는다. 발걸음은 짧고 뭉툭한 스터브 (손·발가락 없음) |
| 카메라 | 고정. 부라봉 전신. 세로 프레임 활용 |
| 부라봉 표정 | 평온, 호기심 어린 눈 (정원). 잎사귀가 바람에 살짝 흔들림 |
| 대사 | "와... 여기 뭐야? 공기가 정말 상쾌하다봉~" |
| 자막 | "제주 비자림 🌿" |
| 사운드 | 숲의 자연소리(바람, 잎사귀) + 가벼운 BGM |

### 장면 2 — 거대한 비자나무 발견 (3-6초)

| 요소 | 내용 |
|---|---|
| 화면 | 부라봉이 멈춰 선다. 시선이 위로 향한다. 수백 년 된 거대한 비자나무가 프레임 상단을 가득 채움 |
| 카메라 | 부라봉(전경) → 나무(후경) 구도. 또는 부라봉 시선 방향으로 컷 전환 |
| 부라봉 표정 | 눈이 동그래짐. 약간 위로 향한 시선 |
| 대사 | "와... 이 나무 뭐냐봉? 엄청 크다봉!" |
| 자막 | "이게 다 나무라고?!" |
| 사운드 | 발견의 놀란 효과음 + BGM 살짝 텐션 |

### 장면 3 — 크기 비교 (6-9초)

| 요소 | 내용 |
|---|---|
| 화면 | 부라봉이 나무 옆에 서서 자신의 키와 나무를 비교한다. 부라봉이 아주 작아 보이는 구도 (나무의 거대함 강조) |
| 카메라 | 부라봉+나무 대비 구도. 부라봉은 프레임 하단 작은 크기로 |
| 부라봉 표정 | 놀란 눈이 더 커짐. 입이 살짝 벌어지고 갈매기 형태 유지. 코믹한 과장 |
| 대사 | "이게 다 나무라고? 나보다 훨씬 크다봉! 경이롭다봉~" |
| 자막 | "부라봉 vs 비자나무 📏" |
| 사운드 | 코믹 비교 효과음 + BGM 경쾌하게 |

### 장면 4 — 감탄의 포즈 (9-12초)

| 요소 | 내용 |
|---|---|
| 화면 | 부라봉이 두 팔을 벌려 나무를 향해 감탄하는 포즈. 팔은 짧고 뭉툭한 스터브 (손 없음) |
| 카메라 | 부라봉 전신. 나무는 배경에서 거대하게 |
| 부라봉 표정 | 감동에 찬 눈, 갈매기 미소. 행복한 표정 |
| 대사 | "이 나무 나이가 몇 살일까봉? 정말 대단하다봉~ 존경한다봉!" |
| 자막 | "경이롭다봉 ✨" |
| 사운드 | 감탄 효과음 + BGM 웅장하게 (약간) |

### 장면 5 — 마무리 (12-15초)

| 요소 | 내용 |
|---|---|
| 화면 | 부라봉이 나무를 바라보며 미소. 나뭇잎 사이로 햇살이 비침. 하단 중앙에 로고 |
| 카메라 | 부라봉 반신 또는 전신. 나무가 배경 |
| 부라봉 표정 | 만족스러운 미소. 편안한 자세 (나무에 살짝 기대어도 좋음) |
| 대사 | "다음에 또 오겠다봉! 나무야 오래오래 살아라봉~" |
| 자막 | "비자림 숲길 산책 🌲" + 로고 |
| 사운드 | BGM 페이드아웃 + 자연 잔향 |

## 캐릭터 외형 체크리스트 (장면별)

| 장면 | 눈 | 입 | 잎사귀 위치 | 볼 | 비고 |
|---|---|---|---|---|---|
| 1 | 정원, 평온 | 갈매기 약간 열린 | 정상 | 진한 주황 | 산책 중 |
| 2 | 동그랗게 | 갈매기 살짝 벌림 | 정상 | 진한 주황 | 발견 |
| 3 | 동그랗게 (더 큼) | 갈매기 벌림 + 코믹 | 정상 | 진한 주황 | 비교 |
| 4 | 감동에 찬 눈 (반짝) | 갈매기 미소 | 정상 | 진한 주황 | 감탄 |
| 5 | 정원 또는 살짝 감은 눈 | 갈매기 미소 | 정상 | 진한 주황 | 만족 |

## 기술 노트

- **프레임**: 1080×1920 (9:16)
- **길이**: 총 15초 (장면당 약 3초)
- **대비 구도**: 장면 3에서 부라봉과 나무의 크기 대비가 핵심 메시지. 부라봉은 프레임 하단 작은 크기로
- **나무 표현**: 비자나무의 질감, 수백 년 된 느낌의 굵은 줄기. 실제 비자림 사진/영상 참고
- **색감**: 초록 숲 + 주황 부라봉 대비
