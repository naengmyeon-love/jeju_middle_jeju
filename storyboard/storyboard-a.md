# 스토리보드 A — 비자림 숲길 산책 (찾기 대작전)

> 기획안 A 기반: 더위에 지친 부라봉이 시원한 곳을 찾는 코믹 탐색극

---

## 기본 정보

| 항목 | 내용 |
|---|---|
| 제목 | 비자림 숲길 산책 — 부라봉의 시원한 찾기 대작전 |
| 길이 | 15초 |
| 비율 | 9:16 (세로형) |
| 캐릭터 | 부라봉 (단일) |
| 배경 | 제주 비자림 숲길 |

---

## 장면별 구성

### 장면 1 — 더위 속 등장 (0-3초)

| 요소 | 내용 |
|---|---|
| 화면 | 비자림 숲길 입구. 푸른 잎사귀가 프레임 상단을 채운다. 부라봉이 아래에서 위로 등장하며 헥헥거리는 표정 |
| 카메라 | 고정 또는 살짝 줌인. 세로 프레임 가득 부라봉의 전신(1.5등신) |
| 부라봉 표정 | 헥헥, 혀 살짝 내밀거나 땀(이마/볼) 표현. 눈은 정원 |
| 대사 | "아~ 더워죽겠다봉... 여름은 왜 이렇게 뜨거운 거냐봉?" |
| 자막 | "여름의 비자림 🌿" |
| 사운드 | 숲의 자연소리 + 덥다는 느낌의 경쾌한 효과음 + BGM 시작 |

### 장면 2 — 탐색 (3-6초)

| 요소 | 내용 |
|---|---|
| 화면 | 부라봉이 두리번거리며 주변 살핌. 커다란 비자나무들이 배경. 부라봉의 시선이 좌우로 움직임 |
| 카메라 | 부라봉 중심으로 살짝 패닝. 배경은 흐릿하게 (포커스 부라봉) |
| 부라봉 표정 | 궁금해하는 눈, 약간 갸웃. 여전히 더위에 지친 느낌 |
| 대사 | "시원한 곳 어디 없냐봉? 나무 그늘 같은 거..." |
| 자막 | (없음) |
| 사운드 | 두리번거리는 코믹 효과음 + BGM 지속 |

### 장면 3 — 발견 (6-9초)

| 요소 | 내용 |
|---|---|
| 화면 | 부라봉의 시선이 커다란 비자나무에 닿음. 나무가 프레임에 크게 들어옴. 부라봉 눈이 동그래짐 |
| 카메라 | 부라봉의 시선 방향으로 전환하거나, 부라봉+나무 함께 담은 와이드 → 나무 클로즈업 |
| 부라봉 표정 | 놀란 눈(동그랗게), 입이 살짝 벌어짐 (갈매기 형태 유지) |
| 대사 | "와... 이 나무 뭐냐봉? 엄청 크다봉!" |
| 자막 | "이게 다 나무라고?!" |
| 사운드 | 발견의 "오!" 효과음 + BGM 살짝 텐션 업 |

### 장면 4 — 그늘 휴식 (9-12초)

| 요소 | 내용 |
|---|---|
| 화면 | 부라봉이 나무 그늘로 들어가 시원한 표정. 나무 그늘과 부라봉의 대비가 보임 |
| 카메라 | 부라봉 클로즈업 또는 나무 그늘 안의 부라봉 전신 |
| 부라봉 표정 | 시원함에 행복한 표정. 눈이 반짝이며 미소 (윗입술 갈매기) |
| 대사 | "여기가 천국이다봉! 나무 그늘 최고다봉~" |
| 자막 | "천국 발견 ✨" |
| 사운드 | 시원한 느낌의 효과음 + BGM 릴렉스 |

### 장면 5 — 마무리 (12-15초)

| 요소 | 내용 |
|---|---|
| 화면 | 부라봉이 나무에 기대어 행복한 표정. 잎사귀 사이로 햇살이 비침. 하단 중앙에 로고 |
| 카메라 | 부라봉 전신 또는 반신. 안정적인 구도 |
| 부라봉 표정 | 만족스러운 미소, 편안한 자세 |
| 대사 | "그래도 숲은 좋다봉~ 비자림 최고다봉!" |
| 자막 | "비자림 숲길 산책 🌲" + 로고 |
| 사운드 | BGM 페이드아웃 + 자연의 잔향 |

## 캐릭터 외형 체크리스트 (장면별)

| 장면 | 눈 | 입 | 잎사귀 위치 | 볼 | 비고 |
|---|---|---|---|---|---|
| 1 | 정원 | 갈매기(헥헥) | 정상 위치 | 진한 주황 | 더위 표현 |
| 2 | 정원, 약간 갸웃 | 갈매기 | 정상 위치 | 진한 주황 | 탐색 중 |
| 3 | 동그랗게 (평소보다 살짝 큼) | 갈매기 살짝 벌림 | 정상 위치 | 진한 주황 | 놀람 |
| 4 | 반짝임 (살짝 큼) | 갈매기 미소 | 정상 위치 | 진한 주황 | 행복 |
| 5 | 정원 또는 살짝 감은 눈 | 갈매기 미소 | 정상 위치 | 진한 주황 | 만족 |

## 기술 노트

- **프레임**: 1080×1920 (9:16)
- **길이**: 총 15초 (장면당 약 3초)
- **부라봉 위치**: 프레임 하단 1/3~1/2 지점 중심. 머리(잎사귀 포함)가 상단 여유 공간 활용
- **배경**: 비자림의 푸른 색감. 자연광. 나무 질감 강조
- **색감**: 제주 자연의 초록 + 부라봉의 주황 대비 극대화
