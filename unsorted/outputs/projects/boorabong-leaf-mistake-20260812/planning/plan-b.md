# 기획안 B — 부라봉, 잎사귀 착각 소동 (대조 강조형)

> 원본 초안: Timely Agent(Solar Pro 4)가 텍스트 문안 단계까지 생성. 이후 Claude Code가 `character-guide` v1.1(2026-08-11) 및 공식 원본 페이지 03·08·09·10을 실제로 확인하고 검토·수정했다.
> 수정 내역: 자막/대사 후보를 부라봉 공식 어미로 교체. 배경을 '고르방의 집 마당'으로 명시. 거울 소품은 담당자 확인 필요로 표시.
> 채택 상태: 조건부 채택 — 담당자 확인 필요 항목 해소 + 제작·비용 승인 전까지 유료 생성 없음.

## 1. 핵심 한 줄

바람에 휘날린 잎사귀와 부라봉 머리 위 잎사귀를 시각적으로 대조해, "내 잎이 날아갔다"는 착각을 더 코믹하게 강조한다.

## 2. 기본 정보

- 콘텐츠 주제: 부라봉이 바람에 날아간 잎사귀를 자기 잎사귀로 착각하는 소동
- 길이: 15초
- 화면 비율: 9:16
- 감정: 즐거움 · 코믹
- 등장 캐릭터: 부라봉 (단독)
- 배경: 고르방의 집 마당 (세부 미확보 — 담당자 확인 필요)
- 수행 범위: 문안 + 프롬프트 조립(텍스트)까지. 이미지·영상 생성은 승인 전까지 없음.

## 3. 장면 흐름(스케치)

1) 마당에서 쉬는 부라봉 establishing, 머리 위 잎사귀를 한 번 더 의식적으로 보여줌.
2) 바람이 불어 다른 잎사귀 하나가 멀리 날아가는 컷을 먼저 보여 착각의 단서를 제공.
3) 부라봉이 그 방향을 따라보다가 자기 머리 위가 허전하다고 느낌.
4) 과장된 더듬기/당황으로 코믹 확대.
5) 손거울 속 자신을 확인, 멀쩡함을 깨닫는 반전.
6) 머쓱한 웃음으로 마무리.

## 4. 타겟 반응

- 날아간 잎과 자기 잎을 헷갈리는 구조를 시각적으로 안내.
- 착각이 더 우스꽝스럽게 보이도록 대비 강조.
- 마지막에 가벼운 안심과 웃음을 남김.

## 5. 가이드 준수 확인

- 부라봉 기억상실 이전 과거를 확정하는 서술 없음.
- 단독 등장이라 관계도·키비례 규칙 해당 없음.
- 색상 서술형만 사용, 구매 유도·부적절 표현 없음.

## 6. 담당자 확인 필요

- 손거울 소품 형태·크기 — 공식 소품 목록 미확보.
- 마당 조경 세부 — 공식 배경 목록 미확보.
- 배경음악·효과음의 저작권 확인 여부.

## 7. 확정 자막/대사 (공식 어미 적용)

- "저 잎사귀, 내 거 아니냐봉?"
- "진짜 없어진 거 맞냐봉?!"
- "오, 그대로 있었다봉!"
- "머쓱하다봉~"
- (효과음) 바람 소리 + 짤막한 코믹 반응음.

## 8. 산출 구분

- B안은 시각적 대조를 활용해 착각을 더 두드러지게 만드는 참조안이다.
- 세 안(A/B/C)은 서로 다른 연출 톤으로 분화한다.
