# 기획안 B — 부라봉, 잎사귀 착각 소동 (대조 강조형)

> 이 문서는 Solar Pro 4가 텍스트 문안 단계까지만 생성한 기획 초안이다. 캐릭터 가이드 적용·준수 판정은 포함하지 않으며, 채택 확정은 Claude Code 검토 전이므로 미채택으로 기록한다.

## 1. 핵심 한 줄

바람에 휘날린 잎사귀와 부라봉 머리 위 잎사귀를 시각적으로 대조해, "내 잎이 날아갔다"는 착각을 더 코믹하게 강조한다.

## 2. 기본 정보

- 콘텐츠 주제: 부라봉이 바람에 날아간 잎사귀를 자기 잎사귀로 착각하는 소동
- 길이: 15초
- 화면 비율: 9:16
- 감정: 즐거움 · 코믹
- 등장 캐릭터: 부라봉
- 수행 범위: 무료 기획 문안까지만(솔라 프로 4 텍스트). 이미지·영상·Claude 인계·외부 배포는 이 smoke test에서 금지.

## 3. 장면 흐름(스케치)

1) 마당에서 쉬는 부라봉 establishing, 머리 위 잎사귀를 한 번 더 의식적으로 보여줌.
2) 바람이 불어 다른 잎사귀 하나가 멀리 날아가는 컷을 먼저 보여 착각의 단서를 제공.
3) 부라봉이 그 방향을 따라보다가 자기 머리 위가 허전하다고 느낌.
4) 과장된 더듬기/당황으로 코믹 확대.
5) 거울 속 자신을 확인, 멀쩡함을 깨닫는 반전.
6) 머쓱한 웃음으로 마무리.

## 4. 타겟 반응

- 날아간 잎과 자기 잎을 헷갈리는 구조를 시각적으로 안내.
- 착각이 더 우스꽝스럽게 보이도록 대비 강조.
- 마지막에 가벼운 안심과 웃음을 남김.

## 5. 금지/주의( 파이프라인 smoke test 기준 )

- 캐릭터 외형·말투의 공식판단은 여기서 하지 않음(미채택).
- 유료 생성, 외부 배포, Claude 인계 없음.
- 자막/대사는 문안 수준의 제안까지만 남김.

## 6. 제안 자막/대사(후보)

- "방금 내 잎…?"
- "아니, 저건?"
- "아, 그대로 있었네…"
- 바람 효과 + 짤막한 코믹 반응음.

## 7. 산출 구분

- B안은 시각적 대조를 활용해 착각을 더 두드러지게 만드는 참조안이다.
- 세 안(A/B/C)은 서로 다른 연출 톤으로 분화한다.
