- `b/scene-01`, `b/scene-05` 등 클로즈업 컷에서 캐릭터 몸체에 그라데이션 음영이 들어갔다. 공식 원화는 플랫 채색이므로 허용 범위인지 확인이 필요하다.
- `b/scene-03`에서 부라봉의 눈 위에 공식에 없는 눈꺼풀 막대가 추가됐다. 공식 "피곤한 눈" 표현의 허용 범위인지 확인이 필요하다.

### 관찰된 생성 경향

동일 프롬프트·동일 레퍼런스 조건에서 **와이드·미디엄 샷일수록 고르방의 둥근 눈이 누락되고, 클로즈업일수록 정확하게 재현된다.** 영상 생성 단계에서는 각 클립의 시작 이미지를 고르방 얼굴이 충분히 크게 잡히는 컷으로 준비하거나, 승인된 공식 원화를 시작 이미지로 고정하는 방식이 필요하다.

## 3. 담당자 확인 필요 항목

1. **비자림 배경 사용 허용 범위** — 비자림은 공식 배경 목록에 없는 제주 실제 장소 기반 확장 배경이다. 사용 가능 여부와 표현 수위를 확인해야 한다. (공식 배경·소품 목록은 가이드 v2.2 "확인 필요" 항목으로 미확보 상태)
2. **실제 지형·시설물 묘사 수위** — 천연기념물 지정 구역의 특정 나무나 안내판을 식별 가능한 형태로 묘사하지 않았는지 최종 확인이 필요하다.
3. **자막 폰트 사용권** — 영상 자막에 사용할 폰트의 상업적 사용권 확인이 필요하다.
4. **캐릭터 합성 스타일** — 실사 배경 위에 플랫 벡터 캐릭터를 합성하는 현재 스타일이 공식 IP 운영 방향과 맞는지 확인이 필요하다.
