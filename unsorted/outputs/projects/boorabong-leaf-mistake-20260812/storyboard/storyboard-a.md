# 스토리보드 A — 부라봉, 잎사귀 착각 소동 (기본 코믹형)

> 원본 초안: Timely Agent(Solar Pro 4) 텍스트 문안. Claude Code가 `character-guide` v1.1 및 공식 페이지 03·08·09·10을 확인하고 검토·수정했다.
> 수정 내역: 자막을 부라봉 공식 어미로 교체, 배경을 '고르방의 집 마당'으로 명시, 각 장면에 정지 이미지 프롬프트용 단일 샷 카메라를 확정(`storyboard/prompts/a1.txt`~`a5.txt`).
> 이미지·영상 생성은 이 단계에서 실행하지 않는다. 장면 설명은 문안·구도·프롬프트까지만 다룬다.

## 기본

- 안: A안(기본 코믹형)
- 길이: 15초
- 비율: 9:16
- 캐릭터: 부라봉
- 감정: 즐거움 · 코믹
- 배경: 고르방의 집 마당
- 범위: 기획 문안 + 프롬프트 조립까지. 이미지·영상 생성은 제작·비용 승인 전까지 없음.

## 장면별 문안

### 장면 1 — establishing (0:00~0:03)

- 내용: 마당에서 쉬고 있는 부라봉. 안정적 첫 인상.
- 구도: 화면 중앙 근처, 세로 프레임에 부라봉이 편안하게 잡힘.
- 정지 이미지 카메라: `front-facing medium shot` (→ `prompts/a1.txt`)
- 표정: 편안한 휴식.
- 자막: 없음.
- 소리: 잔잔한 환경음.

### 장면 2 — 잎사귀 날아감 (0:03~0:06)

- 내용: 바람이 불어 잎사귀 하나가 휙 날아감.
- 구도(영상용 참고): 잎사귀가 프레임 위를 지나가며 시선 유도.
- 정지 이미지 카메라: `front-facing medium shot` — 한 순간(잎이 스치는 순간)으로 고정 (→ `prompts/a2.txt`)
- 표정: 부라봉 고개 들기, 살짝 놀람.
- 자막: "어? 잎이 날아갔다봉!"
- 소리: 바람 스침.

### 장면 3 — 착각 강조 (0:06~0:09)

- 내용: 부라봉이 머리 위를 더듬으며 자기 잎이 사라졌다고 느낌.
- 구도: 클로즈업으로 표정 강조.
- 정지 이미지 카메라: `front-facing close-up` (→ `prompts/a3.txt`)
- 표정: 당황, 코믹. (기본 눈 정원 유지, 세로눈 금지 — character-guide p10)
- 자막: "내 잎사귀가 없어졌냐봉?"
- 소리: 짧은 코믹 반응음.

### 장면 4 — 손거울 확인 (0:09~0:12)

- 내용: 손거울/반사면을 보고 확인, 그대로임을 눈치챔.
- 구도: 거울이 보이는 구도로 대칭/반전 느낌.
- 정지 이미지 카메라: `front-facing medium shot` (→ `prompts/a4.txt`)
- 표정: 의아 → 확인.
- 자막: "어라, 그대로 있다봉?"
- 소리: 확인 느낌의 짧은 음.
- 담당자 확인 필요: 손거울 소품 형태 — 공식 소품 목록 미확보.

### 장면 5 — 머쓱 마무리 (0:12~0:15)

- 내용: 머쓱하게 웃으며 끝.
- 구도: 부라봉 표정 클로즈업.
- 정지 이미지 카메라: `front-facing close-up` (→ `prompts/a5.txt`)
- 표정: 머쓱한 웃음.
- 자막: "머쓱하다봉~"
- 소리: 가벼운 웃음/바람 잔향.

## 안별 차별점

- A안은 클래식한 코믹 흐름: 당황 → 확인 → 머쓱.
- 5장면 전부 부라봉 단독, 공식 6인 외 캐릭터 없음.
- 채택 상태: 조건부 채택. 담당자 확인 필요 항목 해소와 제작·비용 승인 전까지 유료 생성 없음.
