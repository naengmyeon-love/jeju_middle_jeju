# 퐁당패밀리 공식 IP 숏폼 자동 제작 및 감수 파이프라인 명세서

## 1. 성공 기준

프로젝트 완료 여부는 아래 항목을 기준으로 판단한다.

- [ ] 지정된 기획안 폼에 맞춰 스토리 시나리오를 작성했는가
- [ ] 시나리오와 스토리보드 파일이 Markdown(`.md`) 형식으로 저장되었는가
- [ ] 최종 영상 파일이 MP4(`.mp4`) 형식으로 출력되었는가
- [ ] 최종 영상 길이가 60초 미만인가
- [ ] 퐁당패밀리 공식 캐릭터·비주얼·세계관 가이드라인을 준수했는가
- [ ] 직접적인 상품 판매, 구매 유도, 가격·할인·홍보 문구가 포함되지 않았는가
- [ ] 자동 검수 결과와 담당자 최종 검수가 모두 완료되었는가
- [ ] 캐릭터의 외형, 성격, 말투, 관계 설정이 장면별로 일관되게 유지되었는가
- [ ] 생성된 결과물의 수정 사유와 최종 승인 여부가 기록되었는가

---

## 2. 프로젝트 목표

마케터가 간단한 키워드나 주제를 입력하면 다음 결과물을 자동으로 생성하고 검수하는 파이프라인을 구축한다.

1. 퐁당패밀리 숏폼 기획안
2. 스토리 시나리오
3. 서로 다른 연출 방향의 스토리보드 3안
4. 60초 미만의 숏폼 영상
5. 브랜드·캐릭터 가이드라인 자동 검수 결과
6. 담당자 최종 승인 또는 수정 요청 결과

본 프로젝트의 핵심 목표는 **퐁당패밀리 공식 IP의 정체성을 유지하면서 숏폼 콘텐츠 제작량을 확대하고, 담당자 1명이 기획부터 최종 검수까지 효율적으로 운영할 수 있는지 검증하는 것**이다.

## 3. 추진 배경 및 맥락

퐁당패밀리 공식 계정은 상품 판매 메시지를 직접적으로 노출하기보다 캐릭터의 일상과 세계관을 중심으로 대중과 소통하고 팬덤을 형성하는 브랜딩 전략을 지향한다.

이러한 채널 운영 방식에서는 캐릭터의 정체성을 유지한 콘텐츠를 꾸준히 공급하는 것이 중요하다. 그러나 현재 디자인팀은 B2B, B2G, 팝업 등 기존 업무를 함께 수행하고 있어 숏폼 콘텐츠 제작에 필요한 인력과 시간이 부족한 상황이다.

이에 추가 인력 채용이나 고가의 외주 제작에 의존하지 않고, 생성형 AI 도구와 API 기반 자동화 파이프라인을 활용하여 다음 가능성을 검증한다.

- 반복적인 기획 및 제작 업무 자동화
- 캐릭터 가이드라인 자동 주입
- 브랜드 안전성 및 캐릭터 일관성 자동 검수
- 담당자 1인 중심의 최종 승인 체계
- 제작 시간과 비용 절감 효과 측정

주제, 등장 캐릭터, 상황, 핵심 감정 등 최소한의 단답형 정보만 입력해도 시스템이 공식 가이드라인과 제작 규칙을 자동으로 적용해야 한다.

## 5. 입력 항목

사용자는 기획안 입력 폼에서 다음 항목을 입력한다.

### 5.1 필수 입력

- 콘텐츠 주제
- 등장 캐릭터
- 핵심 상황
- 전달하려는 감정 또는 재미 요소
- 희망 영상 길이
- 콘텐츠 비율
- 사용 가능한 생성형 AI 도구 또는 API

### 5.2 선택 입력

- 배경 장소
- 포함할 대사 또는 유행어
- 참고 콘텐츠
- 제외할 표현
- 희망 연출 방식
- 희망 장면 수
- 배경음악 분위기
- 게시 예정 플랫폼

### 5.3 기본값

- 영상 길이: 30초
- 최대 영상 길이: 59초
- 화면 비율: 9:16
- 기본 출력 해상도: 1080 × 1920
- 기본 언어: 한국어
- 기본 스토리보드 수: 3안
- 직접적인 상업 메시지: 사용 금지
- 최종 승인 방식: 담당자 수동 승인 필수

## 6. 전체 처리 흐름

```text
사용자 키워드 입력
        ↓
입력값 유효성 검사
        ↓
공식 캐릭터·비주얼·톤앤매너 가이드 자동 주입
        ↓
기획안 생성
        ↓
시나리오 생성
        ↓
스토리보드 3안 생성
        ↓
기획·캐릭터·브랜드·저작권·기술 사전 검수
        ↓
담당자 스토리보드 선택 및 제작 승인
        ↓
최종 생성 프롬프트·공식 레퍼런스 이미지 검수
        ↓
Higgsfield 예상 크레딧 확인 및 담당자 비용 승인
        ↓
Higgsfield 영상 생성 (유료 호출은 이 단계에서 최초 실행)
        ↓
영상 자동 검수 및 실패 클립만 부분 재생성
        ↓
담당자 최종 영상 검토·승인
        ↓
MP4 출력 및 결과 기록
```

### 6.1 Higgsfield 비용 보호 게이트

- Higgsfield 호출은 기획안·시나리오·스토리보드·생성 프롬프트·공식 레퍼런스 이미지가 모두 검수된 뒤에만 허용한다.
- 담당자가 스토리보드와 예상 크레딧을 명시적으로 승인하기 전에는 테스트 생성을 포함한 모든 유료 호출을 금지한다.
- 캐릭터는 공식 PDF에서 추출한 승인 레퍼런스 이미지 또는 그 원화를 그대로 사용한 고정 시작 이미지로만 생성한다. 텍스트 프롬프트만으로 캐릭터를 새로 생성하지 않는다.
- 사전 검수 실패 시 Higgsfield를 호출하지 않고 무료 문서·이미지 단계로 되돌린다.
- 영상 검수 실패 시 전체 영상을 다시 생성하지 않고 실패한 클립만 재생성한다.
- 최종 영상 승인은 자동 기록하지 않는다. 담당자가 실제 영상을 확인하고 명시적으로 선택한 판정만 기록한다.

## 7. 핵심 기능

### 7.1 기획안 자동 생성

사용자가 입력한 키워드를 기반으로 지정된 기획안 폼에 맞는 콘텐츠 기획안을 생성한다.

기획안에는 최소한 다음 내용이 포함되어야 한다.

- 콘텐츠 제목
- 한 줄 요약
- 제작 목적
- 등장 캐릭터
- 배경 및 상황
- 핵심 갈등 또는 재미 요소
- 시작 장면
- 전개
- 반전 또는 포인트
- 마무리
- 예상 영상 길이
- 장면 수
- 금지 요소 확인
- 가이드라인 준수 여부

### 7.2 시나리오 생성

기획안을 바탕으로 시간대별 시나리오를 생성한다.

각 장면에는 다음 정보를 포함한다.

- 장면 번호
- 시작 및 종료 시간
- 등장 캐릭터
- 행동
- 표정
- 대사
- 배경
- 카메라 구도
- 효과음
- 화면 자막
- 다음 장면과의 연결 방식

### 7.3 스토리보드 3안 생성

동일한 시나리오를 기반으로 서로 구분되는 스토리보드 3개를 생성한다.

- **A안: 기본형**  
  캐릭터와 대사가 명확하게 전달되는 안정적인 연출

- **B안: 코미디형**  
  표정, 타이밍, 반전, 효과음을 강조한 연출

- **C안: 감성형 또는 세계관 확장형**  
  캐릭터 관계와 퐁당패밀리 세계관을 강조한 연출

각 안은 단순 문장 변경이 아니라 카메라 구도, 장면 구성, 타이밍 또는 연출 의도가 명확히 달라야 한다.

각 안의 모든 장면에는 공식 캐릭터 레퍼런스를 기반으로 생성한 PNG 이미지를 포함한다.
스토리보드 Markdown은 장면 이미지와 스토리·행동·대사·카메라·효과음 정보를 함께 보여줘야 한다.
대사와 자막은 이미지에 직접 굽지 않고 Markdown 텍스트로 표기한다.

### 7.4 공식 가이드 자동 주입

스토리 및 영상 생성 전에 다음 정보가 시스템 프롬프트 또는 고정 컨텍스트로 자동 적용되어야 한다.

- 캐릭터별 공식 외형
- 캐릭터별 성격
- 캐릭터별 말투
- 캐릭터 간 관계
- 허용되는 행동
- 금지되는 행동
- 공식 색상
- 로고 사용 규칙
- 배경 및 소품 사용 규칙
- 세계관 설정
- 상업적 표현 제한
- 부적절한 표현 및 민감 요소 제한

### 7.5 자동 품질 검수

생성 결과물을 다음 기준으로 자동 검사한다.

#### 캐릭터 검수

- 공식 외형과 일치하는가
- 캐릭터별 성격이 유지되는가
- 말투와 어미가 일관적인가
- 캐릭터 간 관계가 설정과 일치하는가
- 장면마다 신체 특징과 색상이 유지되는가
- 다른 캐릭터의 특징이 혼합되지 않았는가

#### 스토리 검수

- 60초 미만으로 구현 가능한가
- 장면 수가 과도하지 않은가
- 시작, 전개, 포인트, 마무리가 존재하는가
- 장면 간 인과관계가 자연스러운가
- 캐릭터 일상과 세계관 중심으로 구성되었는가
- 갑작스러운 설정 변경이 없는가

#### 브랜드 안전성 검수

- 직접적인 구매 유도 문구가 없는가
- 가격, 할인, 판매, 링크 클릭 유도 문구가 없는가
- 상품 기능을 과장하거나 반복 노출하지 않는가
- 폭력적, 선정적, 혐오적, 정치적, 종교적 표현이 없는가
- 타인의 상표, 캐릭터, 음악, 이미지를 무단으로 사용하지 않는가
- 퐁당패밀리의 이미지에 부정적 영향을 줄 표현이 없는가

#### 기술 검수

- 시나리오와 스토리보드가 `.md` 형식인가
- 모든 스토리보드 장면 이미지가 `.png`로 존재하고 Markdown에서 열리는가
- 장면 이미지가 스토리·행동·표정·배경·카메라 설명과 일치하는가
- 최종 영상이 `.mp4` 형식인가
- 영상 길이가 60초 미만인가
- 영상 비율이 9:16인가
- 영상과 음성이 정상적으로 재생되는가
- 자막이 화면 밖으로 잘리지 않는가
- 대사와 입 모양 또는 장면 타이밍이 지나치게 어긋나지 않는가

### 7.6 담당자 최종 검수

자동 검수를 통과하더라도 영상은 자동 게시하지 않는다.  
담당자가 다음 항목을 직접 확인한 후 승인해야 한다.

- 캐릭터 정체성
- 스토리의 재미와 자연스러움
- 공식 계정에 게시하기 적절한지 여부
- 상업적 메시지 노출 여부
- 이미지·음원·폰트 등 저작권 문제
- 영상 품질
- 오탈자 및 자막 오류

담당자는 다음 중 하나를 선택할 수 있다.

- 승인
- 부분 수정
- 전면 재생성
- 게시 보류
- 폐기

## 10. 제약 조건

- 퐁당패밀리 공식 가이드라인을 반드시 준수한다.
- 직접적이고 노골적인 상품 판매 내용은 포함하지 않는다.
- 모든 결과물은 자동 검수와 담당자 검수를 모두 거친다.
- 영상 길이는 반드시 60초 미만으로 제한한다.
- 캐릭터의 외형, 성격, 말투를 임의로 변경하지 않는다.
- 공식적으로 승인되지 않은 설정을 사실처럼 추가하지 않는다.
- 생성형 AI가 만든 결과물은 초안으로 간주한다.
- 저작권이 확인되지 않은 음악, 폰트, 이미지, 음성을 사용하지 않는다.
- 사용한 생성형 AI 도구와 제작 조건을 기록한다.
- 최종 결과물은 담당자 승인 전 외부에 공개하지 않는다.

## 15. 검수 결과 형식

자동 검수 결과는 각 항목에 대해 통과 여부와 근거를 함께 출력한다.

```md
# 자동 검수 결과

## 종합 결과

- 판정: 통과 / 조건부 통과 / 실패
- 총점:
- 필수 수정 여부:
- 주요 위험 요소:

## 상세 검수

| 검수 항목 | 결과 | 근거 | 수정 제안 |
|---|---|---|---|
| 영상 길이 | 통과 | 예상 길이 32초 | 없음 |
| 캐릭터 말투 | 실패 | 장면 3의 어미가 공식 말투와 다름 | 공식 어미로 수정 |
| 상업성 노출 | 통과 | 구매 유도 문구 없음 | 없음 |
```

### 검수 판정 기준

- **통과**: 모든 필수 기준을 충족함
- **조건부 통과**: 경미한 수정 후 제작 또는 게시 가능
- **실패**: 캐릭터 훼손, 상업성 노출, 저작권 위험 등 중대한 문제가 있음

다음 항목 중 하나라도 실패하면 최종 판정은 자동으로 `실패` 처리한다.

- 캐릭터 공식 외형 훼손
- 캐릭터 성격 또는 말투의 중대한 불일치
- 직접적인 상품 판매 또는 구매 유도
- 영상 길이 60초 이상
- 저작권 침해 가능성이 높은 요소 포함
- 담당자 검수 누락

## 17. 비기능 요구사항

### 17.1 사용성

- 사용자는 복잡한 프롬프트를 작성하지 않아도 된다.
- 입력 폼은 비전문가도 이해할 수 있는 용어를 사용한다.
- 오류 발생 시 원인과 수정 방법을 명확하게 안내한다.
- 생성된 기획안과 시나리오는 담당자가 직접 수정할 수 있어야 한다.

### 17.2 일관성

- 동일한 캐릭터 가이드와 입력 조건에서는 유사한 품질의 결과를 생성해야 한다.
- 캐릭터 정보는 단일 가이드 데이터에서 불러와야 한다.
- 프롬프트에 공식 가이드가 중복되거나 상충되지 않도록 관리한다.

### 17.3 추적성

- 사용자의 입력값을 기록한다.
- 사용한 모델과 버전을 기록한다.
- 생성 일시를 기록한다.
- 자동 검수 결과를 기록한다.
- 담당자의 수정 내용과 승인 결과를 기록한다.
- 최종 영상 파일과 기획 문서의 버전을 연결한다.

### 17.4 보안

- 공식 캐릭터 가이드 원본은 권한이 있는 사용자만 열람할 수 있어야 한다.
- 외부 AI 서비스로 전송되는 데이터 범위를 사전에 확인해야 한다.
- 미공개 캐릭터 설정과 내부 자료가 외부에 노출되지 않도록 한다.
- API 키는 코드나 문서에 직접 작성하지 않고 환경변수로 관리한다.

## 18. 예외 처리

- 필수 입력값이 누락되면 생성을 시작하지 않는다.
- 공식 가이드가 연결되지 않은 경우 결과물을 생성하지 않는다.
- 영상 길이가 60초 이상이면 자동으로 재편집하거나 재생성을 요청한다.
- 검수 실패 항목이 있으면 영상 생성 또는 최종 출력을 중단한다.
- 영상 생성 API 오류 발생 시 오류 원인과 재시도 가능 여부를 기록한다.
- 생성 결과에서 캐릭터 외형이 크게 달라진 경우 해당 장면만 재생성할 수 있어야 한다.
- 저작권 위험 요소가 감지되면 대체 가능한 음원, 폰트 또는 이미지를 제안한다.

## 21. 공식 캐릭터 가이드 연동

### 21.1 기준 파일

본 파이프라인은 다음 파일을 캐릭터 및 브랜드 검수 기준으로 사용한다.

1. `제주애퐁당 캐릭터 사용 매뉴얼.pdf`: 공식 원본
2. `character-guide.md`: 담당자와 AI가 읽는 구조화 운영 문서
3. `character-guide.json`: 백엔드와 자동 검수 모듈이 사용하는 데이터

### 21.2 적용 우선순위

```text
공식 PDF
   ↓
character-guide.md / character-guide.json
   ↓
사용자 입력
   ↓
AI 생성 결과
```

문서 간 충돌이 발생하면 공식 PDF를 우선한다.

### 21.3 생성 전 Pre-Hook

콘텐츠 생성 전에 선택된 캐릭터의 공식 외형, 핵심 성격, 권장 말투, 관계, 금지 행동, 세계관 및 브랜드 안전성 규칙을 자동으로 프롬프트에 주입한다.

공식 가이드에 없는 정보는 AI가 임의로 확정하지 않고 `담당자 확인 필요`로 표시한다.

### 21.4 생성 후 Quality Guard

1. 캐릭터 이름과 등장 여부 검사
2. 외형 핵심 요소 검사
3. 성격과 행동 일치 여부 검사
4. 말투와 대사 적합성 검사
5. 관계 설정 충돌 검사
6. 금지 행동 및 상업성 검사
7. 공식 설정에 없는 정보 검사
8. 영상 길이와 파일 형식 검사
9. 담당자 최종 승인 요청

### 21.5 판정 기준

| 판정 | 기준 | 처리 |
|---|---|---|
| 통과 | 공식 가이드와 충돌 없음 | 다음 단계 진행 |
| 조건부 통과 | 경미한 말투·표현 수정 필요 | 수정 후 재검수 |
| 실패 | 외형 훼손, 관계 변경, 직접 판매, 중대한 설정 충돌 | 생성 중단 및 재생성 |
| 확인 필요 | 공식 자료만으로 판단 불가 | 담당자 수동 확인 |
