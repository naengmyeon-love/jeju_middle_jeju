# 스토리보드 B안 — 코미디형

> **일러두기 (담당자 확인 전 임시안)**
> planning/scenario.md에서 "담당자 확인 필요"로 표시된 항목(대사, 자막, 배경음악, 효과음, 비자림 구체 촬영 구역)은 이 문서에서도 임시안을 그대로 유지한다. 확정 전까지 촬영·생성에 참고용으로만 사용한다.

## 연출 방향

- 연출 콘셉트: 표정·타이밍·반전·효과음을 강조한 연출. 15초를 A안(3장면·5초씩)보다 잘게 쪼갠 4장면으로 재배분해, 지침→반전→더 큰 반전(발견)→얼음 엔딩의 리듬을 빠르게 끊어 친다.
- 목표 감정: 웃음, 놀라움, 반전 재미
- 총 길이: 15초
- 장면 수: 4장면 (scenario.md의 3장면을 코미디 타이밍에 맞게 재배분: 장면1을 2컷으로 분리, 장면2를 통 컷으로 압축, 장면3은 그대로 유지)

> "생성 프롬프트(영상용)" 칸은 점프컷·줌·팬 등 **영상 연출 지시**가 포함된 초안이다. 정지 이미지 생성에는 이 문구를 쓰지 않았다. 실제 영상 생성 시 `video-generator` 단계에서 `higgsfield-prompt-builder`로 다시 조립해야 한다.

## 장면별 이미지 보드

### 장면 1 · 00:00~00:02

**이미지 생성 대기 — 아래 "이미지 생성 기록" 참고**

- **스토리:** 코미디형 오프닝은 "더위에 찌든 얼굴"을 강한 클로즈업으로 먼저 못박아, 다음 컷의 반전(시원함)을 더 크게 느끼게 만든다.
- **화면:** 뙤약볕이 내리쬐는 비자림 숲길 입구.
- **캐릭터:** 과장되게 처진 눈, 크게 내려간 입꼬리, 축 늘어진 이파리.
- **대사·자막:** "더워서 축 늘어지겠다봉..." / **더위 지침!!** (화면 상단, 큰 강조 자막)
- **정지 이미지 순간(선택 근거):** 지침의 정점 한 순간만 골랐다. 걷는 동작과 표정 변화를 한 컷에 섞지 않기 위해 A안의 장면1을 두 컷(1·2)으로 나눴다.
- **카메라(정지 이미지용):** `front-facing extreme close-up`
- **효과음·음악:** 매미 소리 최고조, 늘어지는 느낌의 효과음
- **영상 생성 프롬프트(참고 초안):** 위 요약표 1행 참고.
- **이미지 생성 기록:**
  - 레퍼런스: `shared/references/pages/page-08.png`, `page-09.png`, `page-10.png` — `view_image`로 확인 완료.
  - 조립 도구: `node unsorted/scripts/build-pongdang-prompt.mjs`.
  - 정지 이미지 입력 게이트: 통과 (샷 1개 `extreme close-up`).
  - 조립된 프롬프트 [SCENE] 블록: `BOO RABONG's face shows exaggerated tired half-lidded eyes and a deeply downturned mouth, leaves drooping limp under scorching sun. Background is a blazing sunlit forest trail entrance.`
  - 실행 명령: `higgsfield generate create nano_banana_flash --prompt '...' --image 'shared/references/pages/page-08.png' --image 'shared/references/pages/page-09.png' --image 'shared/references/pages/page-10.png' --aspect_ratio 9:16 --resolution 2k --wait`
  - **생성 미실행 사유:** `metadata/production-log.json`의 `approvals.production.status`가 `not_requested`(제작·비용 승인 미기록)이며, 이번 세션에서 `higgsfield` CLI 직접 호출이 권한 정책상 차단됨(`This command requires approval`). 프롬프트 조립은 완료. 재생성 가능 여부: 가능 — 승인 및 CLI 실행 권한 확보 후 위 명령 실행.
