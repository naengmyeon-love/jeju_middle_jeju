# 기획안 B — 비자림 숲길 산책 (부라봉의 비자나무 감탄)

## 1. 개요

| 항목 | 내용 |
|---|---|
| 제목 | 비자림 숲길 산책 — 부라봉의 비자나무 감탄 |
| 길이 | 15초 |
| 화면 비율 | 9:16 (세로형 숏폼) |
| 감정 | 즐거움 · 코믹 |
| 등장 캐릭터 | 부라봉 |
| 배경 | 제주 비자림 숲길, 수백 년 된 비자나무 |

## 2. 콘셉트

부라봉이 비자림을 걷다가 눈앞에 나타난 수백 년 된 거대한 비자나무를 보고 압도당하는 코믹한 반응. "이게 다 나무라고? 나보다 훨씬 크다봉!" 하며 비교하는 단순한 상황.

## 3. 타겟

- 거대한 자연물에 대한 경이로움을 공감할 사람들
- 부라봉의 순수하고 과장된 반응을 좋아하는 팬
- 제주 비자림의 실제 풍경을 아는 사람들

## 4. 핵심 메시지

"자연의 위대함 앞에 작아지는 부라봉의 순수한 감탄"

## 5. 장면 구성 (15초)

| 시간 | 장면 | 설명 |
|---|---|---|
| 0-3초 | 비자림 산책 | 부라봉이 숲길을 걷다가 멈춤. "와... 여기 뭐야?" |
| 3-6초 | 거대한 비자나무 발견 | 수백 년 된 비자나무의 밑둥과 줄기를 올려다봄. 눈이 동그래짐 |
| 6-9초 | 크기 비교 코믹 | 부라봉이 자신의 키와 나무를 비교하며 "이게 다 나무라고? 나보다 훨씬 크다봉!" |
| 9-12초 | 감탄의 포즈 | 부라봉이 두 팔을 벌려 "경이롭다봉~" 하며 감탄 |
| 12-15초 | 마무리 | 나무를 감탄하며 바라보는 부라봉. "나무야 존경한다봉!" 자막 + 로고 |

## 6. 톤앤매너

- 자연의 아름다움에 대한 순수한 감탄
- 부라봉의 과장된 반응으로 코믹함
- 제주의 실제 자연 명소(비자림)를 배경으로 한 리얼리티 요소
- 마지막에 존경/감탄으로 마무리

## 7. 캐릭터 가이드 준수 사항

- 부라봉 어미: `~다봉`, `~라봉`, `~냐봉` 사용
- 부라봉 외형: 1.5등신, 주황 한라봉 몸체, 초록 꼭지와 잎, 양쪽 진한 주황 볼, 흰색 하의
- 눈: 평소 눈과 동일 사이즈, 동그란 눈 허용 (놀람 표현)
- 윗입술: 갈매기(3자) 형태 유지
- 무대: 비자림 (자연 배경 — 공식 배경 목록에 없어 담당자 확인 필요)
- 부라봉 단독 등장

## 8. 비고

- 비자나무의 실제 크기감을 살려 부라봉과의 대비 강조
- 단순하고 이해하기 쉬운 상황
- 부라봉의 호기심과 긍정 에너지 표현
