# ⑥ 클릭형 프론트엔드 프로토타입

- 상태: 구현·검증 완료 v1.0
- 실행 위치: `pongdangpongdang/webapp`
- 실행 명령: `npm run dev`
- 로컬 주소: `http://localhost:3000/`
- 데이터: 전부 브라우저 메모리의 가상 데이터이며 실제 비용·게시·승인은 발생하지 않는다.

## 구현 범위

1. 콘텐츠 담당자와 콘텐츠 팀장 역할 전환
2. 홈, 프로젝트, 승인함, 배포 일정, 제작 이력 메뉴
3. 입력 검증부터 이력 기록까지 15단계 이동
4. 공식 부라봉 레퍼런스 확인 기록과 PNG 미리보기
5. 기획 자동 검수의 조건부 통과, 수정, 재검수
6. 스토리보드 A/B/C 비교와 한 안 선택
7. 제작·비용 승인 전 유료 영상 생성 잠금
8. 영상 생성의 부분 실패와 실패 클립만 재시도
9. 비용 한도 초과 시 자동 중단과 콘텐츠 담당자의 수정 금액 재승인
10. 영상 조건부 통과, 수정, 재검수
11. 팀장의 최종 영상 승인 또는 수정 요청
12. 콘텐츠 담당자의 배포안 작성과 팀장의 별도 배포 승인
13. 배포 승인 전 게시·예약 잠금
14. 승인 조건에 따른 가상 예약과 팀장의 게시 후 철회 확인
15. 버전·검수·승인·비용·배포 이벤트 이력

## 데모 진입점

- `처음부터`: 기획 자동 검수의 조건부 통과 상태에서 시작
- `최종 승인 대기`: 팀장이 영상 v5를 검토하는 상태로 이동
- `배포 승인 대기`: 팀장이 플랫폼·계정·문안·시각을 검토하는 상태로 이동

## 안전 게이트

| 실행 | 해제 조건 | 실행 역할 |
|---|---|---|
| 유료 영상 생성 | 스토리보드 선택 + 제작·비용 승인 | 콘텐츠 담당자 |
| 최종본 확정 | 영상 자동 검수 통과 | 콘텐츠 팀장 |
| 배포 승인 요청 | 최종 영상 승인 + 배포안 작성 | 콘텐츠 담당자 |
| 게시·예약 | 별도 배포 승인 | 콘텐츠 담당자 |
| 게시 후 비공개 | 팀장의 별도 철회 확인 | 콘텐츠 팀장 |

## 검증 결과

- 프로덕션 빌드 성공
- 데스크톱 1440×900: 가로 넘침 없음
- 모바일 390×844: 가로 넘침 없음, 역할 전환·단계 탐색 가능
- 브라우저 경고·오류 없음
- 실제 클릭으로 정상 흐름, 반려·재검수, 부분 생성 실패, 비용 초과·재승인, 별도 배포 승인, 철회 흐름 확인

## ⑦ 연결 단계에서 교체할 가상 영역

- 사내 로그인·권한 및 조직 정보
- 공식 가이드 저장소와 파일 원본 해시
- 기획·시나리오·스토리보드 문서 저장
- 영상 생성 API와 실제 크레딧·비용 조회
- 자동 검수 서비스
- 승인 전자서명·감사 로그 저장소
- Instagram·YouTube·TikTok 게시 API
- 영구 데이터베이스, 백업, 오류 모니터링

실제 연결 뒤에도 현재의 상태 머신과 승인 게이트를 서버에서 다시 강제해야 한다. 프론트엔드 버튼 잠금만으로 유료 호출과 외부 게시를 보호하지 않는다.
