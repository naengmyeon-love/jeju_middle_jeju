# 기획안 C — 부라봉, 잎사귀 착각 소동 (감성형/세계관확장형)

> 원본 초안: Timely Agent(Solar Pro 4)가 텍스트 문안 단계까지 생성. 이후 Claude Code가 `character-guide` v1.1(2026-08-11) 및 공식 원본 페이지 03·08·09·10을 실제로 확인하고 검토·수정했다.
> 수정 내역: 자막/대사 후보를 부라봉 공식 어미로 교체. 배경을 '고르방의 집 마당'으로 명시. 거울 소품은 담당자 확인 필요로 표시.
> 채택 상태: 조건부 채택 — 담당자 확인 필요 항목 해소 + 제작·비용 승인 전까지 유료 생성 없음.

## 1. 핵심 한 줄

부라봉이 잎사귀를 잃어버렸다고 잠깐 속상해하지만, 거울로 확인한 뒤 스스로 머쓱하게 웃으며 마음이 풀린다. 짧고 조용한 소동 속 가벼운 세계관 분위기를 남긴다.

## 2. 기본 정보

- 콘텐츠 주제: 부라봉이 바람에 날아간 잎사귀를 자기 잎사귀로 착각하는 소동
- 길이: 15초
- 화면 비율: 9:16
- 감정: 즐거움 · 코믹 (감은 서정적으로, 핵심은 코믹)
- 등장 캐릭터: 부라봉 (단독)
- 배경: 고르방의 집 마당 (세부 미확보 — 담당자 확인 필요)
- 수행 범위: 문안 + 프롬프트 조립(텍스트)까지. 이미지·영상 생성은 승인 전까지 없음.

## 3. 장면 흐름(스케치)

1) 마당에서 느긋하게 쉬는 부라봉의 정적인 한 컷.
2) 바람이 살짝 스치고 잎사귀 하나가 흘러감.
3) 부라봉이 잠시 감소/아쉬움 톤으로 반응.
4) 잎이 없어졌다고 혼잣말하듯 작게 실망하는 코믹한 장면.
5) 손거울/반사면을 보고 확인, 그대로임을 알고 안심하고 웃음.
6) 가볍게 머리를 털듯 웃으며 마무리.

## 4. 타겟 반응

- 짧은 소동이지만 표정의 미세한 변화(당황→안심→웃음)를 살림.
- 코믹하되 과도하지 않은, 약간 따뜻한 마무리.
- 세계관/분위기를 조금 남기는 방향으로 연출 참고.

## 5. 가이드 준수 확인

- 부라봉 기억상실 이전 과거를 확정하는 서술 없음.
- 단독 등장이라 관계도·키비례 규칙 해당 없음.
- 색상 서술형만 사용, 구매 유도·부적절 표현 없음.

## 6. 담당자 확인 필요

- 손거울/반사면 소품 형태 — 공식 소품 목록 미확보.
- 마당 조경 세부 — 공식 배경 목록 미확보.
- 배경음악·효과음의 저작권 확인 여부.

## 7. 확정 자막/대사 (공식 어미 적용)

- "어… 내 잎 맞냐봉?"
- "잎이 없어졌다봉…"
- "다행이다봉, 그대로 있다봉."
- "머쓱하게 웃는다봉."
- (효과음) 부드러운 바람 소리 + 가벼운 웃음.

## 8. 산출 구분

- C안은 감성형/세계관확장형의 참조안이다. 코믹 핵심은 유지하되 톤을 조금 더 부드럽고 짧게 가져간다.
- 세 안(A/B/C)은 서로 다른 연출 톤으로 분화한다.
