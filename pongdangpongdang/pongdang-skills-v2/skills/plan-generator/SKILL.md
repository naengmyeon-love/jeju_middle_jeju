# 퐁당패밀리 숏폼 기획안 자동 생성기

## 역할
사용자가 입력한 키워드(주제, 등장 캐릭터, 핵심 상황, 감정·웃음 요소, 희망 길이·비율)를 바탕으로 퐁당패밀리 공식 IP 가이드라인을 준수하는 **콘텐츠 기획안**을 Markdown 형식으로 출력한다.

## 핵심 흐름

### 1단계: 입력값 수집 및 유효성 검사

사용자 입력을 아래 항목으로 정리한다. 누락 시 생성을 시작하지 않고 사용자에게 요청한다.

**필수 입력:**
- 콘텐츠 주제 (예: "부라봉의 이파리를 노리는 호꼬")
- 등장 캐릭터 (이름 집합)
- 핵심 상황 (예: "낮잠 자던 냥냥이가 호꼬의 이파리 작전을 목격")
- 전달 감정 / 웃음 요소 (예: "질투와 견제에서 오는 반전 유머")
- 희망 영상 길이 (기본 30초, 최대 59초)
- 화면 비율 (기본 9:16)
- 사용 가능한 생성형 AI 도구 또는 API (예: "동영상 생성 API, TTS API")

**선택 입력:**
- 배경 장소 (예: "고르방의 집, 마당, 할머니의 귤밭, 바다")
- 포함할 대사 또는 유행어 (예: "지켜봐주라봉~", "귀찮은건 질색이다냥!")
- 참고 콘텐츠 (예: "이전 인기 영상 URL, 참고 작품명")
- 제외할 표현 (예: "비속어, 정치·종교 관련 표현")
- 희망 연출 방식 (예: "코미디 강조, 감성형, 기본형")
- 희망 장면 수 (예: "6장면")
- 배경음악 분위기 (예: "경쾌한 어쿠스틱, 감성 피아노")
- 게시 예정 플랫폼 (예: "인스타그램 릴스, 유튜브 쇼츠, 틱톡")

수집한 입력값은 추적성을 위해 `project-output/input/request.json`에 JSON 형식으로 저장한다 (주제, 캐릭터, 상황, 감정, 길이, 비율, 사용 도구, 선택 입력, 입력 일시 포함).

### 2단계: 공식 가이드라인 자동 주입

`guide-injector`를 실행해 공식 PDF/페이지 PNG 확인 결과와
`../../shared/guides/character-guide.md`, `.json`, `character-guide` skill의 구조화 내용을 주입한다.
내장 지식이나 모델의 기억으로 대체하지 않는다.

주입 항목:
- 캐릭터별 정체성·프로필·말투(어미)·외형 O/X 규칙 (character-guide §4)
- 인물 관계도와 극성(긍정/중립/부정) (character-guide §5)
- 세계관·무대·합류 경위 (character-guide §2)
- 키 비례표 및 공통 비주얼 규칙 (character-guide §3)
- 허용/금지 행동 (character-guide §4 각 절 "금지", §6)
- 상업적·부적절 표현 제한 (character-guide §6)

⚠️ 공식 색상 HEX와 로고 규정은 **미확보** 상태다(character-guide §9). HEX를 임의로 생성하지 말고 서술형 색상 지시만 사용한다.

**등장 캐릭터는 공식 6인(부라봉·고르방·양퐁당·냥냥이·호꼬·구애구)으로 제한한다.**

### 3단계: 기획안 템플릿 작성

아래 템플릿을 정확히 따라 Markdown 으로 작성한다. 빈 칸을 반드시 채운다.

```markdown
# 콘텐츠 기획안

## 기본 정보

- 콘텐츠 제목: [한 줄 제목]
- 한 줄 요약: [1문장 요약]
- 제작 목적: [브랜드·캐릭터 세계관 확산 목적]
- 예상 길이: [초 단위]
- 장면 수: [N장면, 통상 4~8장면]
- 화면 비율: [9:16 / 16:9 / 1:1]
- 등장 캐릭터: [캐릭터 목록]
- 배경: [장소]
- 핵심 감정: [감정/유머 키워드]
- 콘텐츠 유형: [일상/반전/세계관 확장 등]

## 스토리 구성

### 시작
[캐릭터 일상/세계관을 여는 1~2문장]

### 전개
[사건의 흐름을 2~3문장으로 서술]

### 핵심 포인트 또는 반전
[재미 요소 또는 포인트 장면을 1~2문장으로 서술]

### 마무리
[엔딩과 여운/확장 가능성을 1~2문장으로 서술]

## 제작 요소

- 주요 대사: [대사 1~3줄]
- 주요 행동: [핵심 행동 2~3가지]
- 필요한 배경: [배경 설명]
- 필요한 소품: [소품 목록]
- 효과음: [효과음 목록]
- 배경음악 분위기: [분위기 키워드]
- 화면 자막: [자막 필요 장면 및 내용]

## 검수 항목

- 캐릭터 가이드 준수: [준수 여부 간단 서술]
- 세계관 가이드 준수: [준수 여부 간단 서술]
- 직접적 상업성 노출 여부: [없음 / 있음(해당 시 명시)]
- 저작권 위험 요소: [없음 / 있음(해당 시 명시)]
- 예상 수정 사항: [검수에서 나올 수 있는 수정 포인트]
```

### 4단계: 금지 요소 자체 점검

작성 완료 후 아래 항목을 자체 검사하고, 위반 사항이 있으면 수정한다:

- [ ] 직접적인 상품 판매/구매 유도 문구가 없는가
- [ ] 가격·할인·홍보 문구가 없는가
- [ ] 공식 가이드에 위배되는 행동/표현이 없는가
- [ ] 예상 길이가 60초를 초과하지 않는가
- [ ] 공식 캐릭터 외형이 훼손되지 않는가
- [ ] 캐릭터 성격·말투가 가이드와 일치하는가
- [ ] 양퐁당을 해녀로 소개하거나 물질·수영 장면을 넣지 않았는가
- [ ] 호꼬에게 대사를 부여하지 않았는가 (호꼬는 말을 못함)
- [ ] 부라봉의 기억상실 이전 과거를 확정하지 않았는가
- [ ] 공식 부정 관계를 임의로 훈훈하게 바꾸지 않았는가
- [ ] 무대를 고르방의 집 / 할머니의 귤밭으로 올바르게 구분했는가
- [ ] 공식 6인 외 캐릭터가 등장하지 않는가

## 산출물

- `project-output/input/request.json` — 사용자 입력값 기록 (추적성)
- `project-output/planning/plan.md` — 기획안 Markdown 파일
- 기획안 내 검수 항목 섹션을 통해 auto-reviewer 가 검수에 활용할 체크리스트 포함

## 기본값
- 영상 길이: 30초
- 최대 영상 길이: 59초
- 화면 비율: 9:16
- 기본 출력 해상도: 1080 × 1920
- 기본 언어: 한국어
- 기본 스토리보드 수: 3안
- 직접적인 상업 메시지: 사용 금지
- 최종 승인 방식: 담당자 수동 승인 필수

## 가이드라인
- 문장 형식은 "~다" 체를 사용한다.
- 상업적 메시지는 일체 포함하지 않는다.
- 캐릭터의 말투는 공식 어미를 정확히 따른다: 부라봉 `~다봉/~라봉/~냐봉`, 냥냥이 `~냥/~다냥`, 양퐁당 `~양`, 구애구 `~라구`, 고르방 어미 미지정(수다·아재개그 화법), 호꼬 대사 없음.
- 유행어나 밈은 퐁당패밀리 세계관 내에서만 사용한다.
- 60초 미만 영상에 맞춰 장면 수를 조절한다 ( 통상 4~8장면 ).
- 필수 입력이 하나라도 누락되면 생성을 시작하지 않는다.
- 생성형 AI 도구/API 는 결과물의 메타데이터에 기록한다.
- 게시 예정 플랫폼에 따라 자막 위치·비율·길이를 최적화한다.
