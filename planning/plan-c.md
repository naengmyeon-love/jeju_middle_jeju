# 기획안 C — 부라봉, 잎사귀 착각 소동 (감성형/세계관확장형)

> 이 문서는 Solar Pro 4가 텍스트 문안 단계까지만 생성한 기획 초안이다. 캐릭터 가이드 적용·준수 판정은 포함하지 않으며, 채택 확정은 Claude Code 검토 전이므로 미채택으로 기록한다.

## 1. 핵심 한 줄

부라봉이 잎사귀를 잃어버렸다고 잠깐 속상해하지만, 거울로 확인한 뒤 스스로 머쓱하게 웃으며 마음이 풀린다. 짧고 조용한 소동 속 가벼운 세계관 분위기를 남긴다.

## 2. 기본 정보

- 콘텐츠 주제: 부라봉이 바람에 날아간 잎사귀를 자기 잎사귀로 착각하는 소동
- 길이: 15초
- 화면 비율: 9:16
- 감정: 즐거움 · 코믹 (감은 서정적으로, 핵심은 코믹)
- 등장 캐릭터: 부라봉
- 수행 범위: 무료 기획 문안까지만(솔라 프로 4 텍스트). 이미지·영상·Claude 인계·외부 배포는 이 smoke test에서 금지.

## 3. 장면 흐름(스케치)

1) 마당에서 느긋하게 쉬는 부라봉의 정적인 한 컷.
2) 바람이 살짝 스치고 잎사귀 하나가 흘러감.
3) 부라봉이 잠시 감소/아쉬움 톤으로 반응.
4) "내 잎이…" 같은 혼잣말을 떠올리는 코믹한 작은 실망.
5) 거울/반사면을 보고 확인, 그대로임을 알고 안심하고 웃음.
6) 가볍게 머리를 털듯 웃으며 마무리.

## 4. 타겟 반응

- 짧은 소동이지만 표정의 미세한 변화(당황→안심→웃음)를 살림.
- 코믹하되 과도하지 않은, 약간 따뜻한 마무리.
- 세계관/분위기를 조금 남기는 방향으로 연출 참고.

## 5. 금지/주의( 파이프라인 smoke test 기준 )

- 캐릭터 외형·말투의 공식판단은 여기서 하지 않음(미채택).
- 유료 생성, 외부 배포, Claude 인계 없음.
- 자막/대사는 문안 수준의 제안까지만 남김.

## 6. 제안 자막/대사(후보)

- "내 잎…?"
- "어, 여기 있네."
- "머쓱…"
- 부드러운 바람 소리 + 가벼운 웃음.

## 7. 산출 구분

- C안은 감성형/세계관확장형의 참조안이다. 코믹 핵심은 유지하되 톤을 조금 더 부드럽고 짧게 가져간다.
- 세 안(A/B/C)은 서로 다른 연출 톤으로 분화한다.
