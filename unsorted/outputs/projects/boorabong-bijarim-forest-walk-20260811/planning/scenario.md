> - 효과음은 숲길이라는 배경 특성상 최소한의 자연음(바람 소리, 새소리, 발소리 등)만 제안했다. 실제 사용 여부·배경음악(BGM) 선곡은 plan.md와 동일하게 **미지정 — 담당자 확인 필요** 상태로 남긴다.
> - 배경(비자림 구체 촬영 구역)도 plan.md와 동일하게 확인 필요 항목이며, 본 시나리오는 사용 승인을 전제로 장면을 구성한 것이 아니다.

## 콘텐츠 정보

- 제목: 부라봉, 그늘 부자 되다봉
- 총 길이: 30초
- 등장 캐릭터: 부라봉 (1인 단독, 다른 캐릭터 등장 없음)
- 핵심 메시지: 더위에 지친 부라봉이 비자림의 거대한 비자나무 그늘을 발견하고 폭 파묻혔다가 화들짝 깨는 코믹한 산책기.

## 장면 구성

### 장면 1

- 시간: [00:00~00:06]
- 배경: 비자림 숲길 산책로 입구 (구체적 촬영 구역 미지정 — 담당자 확인 필요)
- 등장 캐릭터: 부라봉
- 행동: 한여름 더위에 이파리가 축 늘어진 채 터벅터벅 걸어 산책로 입구로 들어선다. 숲의 서늘한 공기가 훅 닿자 걸음을 멈추고 눈이 번쩍 뜨인다.
- 표정: 처음엔 지치고 처진 표정(눈 처짐, 이파리 축 늘어짐) → 시원함을 느끼며 눈이 커지는 놀란 표정 (기본 정원 눈 유지, 세로눈 사용 금지)
- 대사: "아이고, 덥다봉..." (걸어 들어올 때) / "어? 시원하다봉!" (서늘한 공기를 느낀 순간)
- 카메라: 정면 풀샷으로 걸어 들어오는 부라봉을 따라가는 트래킹 샷, 후반부 서늘함을 느끼는 순간 얼굴 클로즈업으로 전환
- 자막: 화면 하단 안전 영역, "무더위 속 산책 시작!" (부라봉 얼굴·꼭지 이파리·볼을 가리지 않는 위치)
- 효과음: 매미 소리가 잦아들며 숲 바람 소리로 전환되는 자연음 (사용 여부 미지정 — 담당자 확인 필요)
- 장면 전환: 컷 전환 (다음 장면으로 자연스럽게 이어지는 연속 동작)

### 장면 2

- 시간: [00:06~00:12]
- 배경: 비자림 산책로 곳곳 (여러 그늘 구간, 구체 구역 미지정 — 담당자 확인 필요)
- 등장 캐릭터: 부라봉
- 행동: 신이 나서 팔짝팔짝 뛰며 산책로 이곳저곳의 그늘을 기웃거린다. 나무 그늘마다 고개를 들이밀었다 빼기를 반복한다.
- 표정: 신나고 들뜬 표정, 볼이 살짝 위로 올라가는 웃는 얼굴
- 대사: "여기도 시원하냐봉?" / "우와, 신난다봉!"
- 카메라: 측면 추적 샷으로 팔짝팔짝 뛰는 부라봉을 따라가는 트래킹, 중간중간 살짝 흔들리는 핸드헬드 느낌의 움직임
- 자막: 화면 상단 안전 영역, "그늘 탐방 중" (부라봉 얼굴을 가리지 않는 위치)
- 효과음: 숲 바람 소리, 낙엽 밟는 발소리, 새소리 (사용 여부 미지정 — 담당자 확인 필요)
- 장면 전환: 점프컷으로 다음 장면의 발견 순간과 연결

### 장면 3

- 시간: [00:12~00:18]
- 배경: 비자림 산책로 중간, 저 멀리 유난히 굵고 우람한 나무가 보이는 지점 (구체 구역 미지정 — 담당자 확인 필요)
- 등장 캐릭터: 부라봉
- 행동: 팔짝거리며 뛰던 부라봉이 저 멀리 유난히 굵고 우람한 나무 한 그루를 발견하고 걸음을 뚝 멈춘다. 그대로 나무를 향해 시선을 고정한다.
- 표정: 눈이 커지고 입이 살짝 벌어지는 놀람과 호기심의 표정 (정원 눈 크기 확대 변형은 공식 감정 변형 범위 내에서만)
- 대사: "어라, 저게 뭐다봉?!"
- 카메라: 부라봉의 뒷모습에서 시작해 시선을 따라 원경의 큰 나무로 패닝, 이어 부라봉 얼굴 클로즈업으로 컷백
- 자막: 화면 하단 안전 영역, "저 멀리, 심상치 않은 나무 발견"
- 효과음: 바람에 나뭇잎이 크게 흔들리는 소리, 놀람을 강조하는 가벼운 효과음 (사용 여부 미지정 — 담당자 확인 필요)
- 장면 전환: 컷 전환 (부라봉이 나무를 향해 다가가는 동작으로 자연스럽게 연결)

### 장면 4

- 시간: [00:18~00:24]
- 배경: 수백 년 된 비자나무 아래 그늘 (구체 구역 미지정 — 담당자 확인 필요)
- 등장 캐릭터: 부라봉
- 행동: 비자나무 밑동부터 우듬지까지 고개를 한껏 젖혀 천천히 올려다보다가, 그대로 나무 그늘 아래 대(大)자로 폭 파묻힌다. 그늘이 너무 시원한 나머지 스르르 눈이 감기려는 찰나, 화들짝 놀라 정신을 차린다.
- 표정: 올려다볼 때는 감탄한 표정 → 파묻힐 때는 나른하고 눈이 스르르 감기는 표정 → 마지막에 화들짝 놀라 눈이 동그래지는 표정 (세로눈 사용 금지, 눈·입 간격 유지)
- 대사: "이야… 엄청 크다봉." (올려다볼 때) / "완전 시원하다봉…" (그늘에 파묻히며 나른하게, 말끝이 늘어짐) / "헉! 잠들 뻔했다봉!" (화들짝 깨며)
- 카메라: 로우앵글 틸트업으로 나무 밑동에서 우듬지까지 따라 올라간 뒤, 부라봉이 그늘에 파묻히는 순간 풀샷으로 전환, 졸음과 놀람은 얼굴 클로즈업으로 강조
- 자막: 화면 하단 안전 영역, "그늘 부자 되는 중 (feat. 조는 중 아님)"
- 효과음: 잔잔한 바람 소리가 점점 아득해지다가, 놀라 깨는 순간 짧고 경쾌한 효과음으로 전환 (사용 여부 미지정 — 담당자 확인 필요)
- 장면 전환: 급전환(빠른 컷)으로 놀람의 코믹함을 강조하며 다음 장면과 연결

### 장면 5

- 시간: [00:24~00:30]
- 배경: 수백 년 된 비자나무 아래에서 이어지는 산책로 (구체 구역 미지정 — 담당자 확인 필요)
- 등장 캐릭터: 부라봉
- 행동: 화들짝 놀라 벌떡 일어난 부라봉이 나무를 향해 꾸벅 인사를 하고, 다시 신나는 발걸음으로 숲길을 걸어간다. 마지막은 걸어가는 뒷모습으로 마무리한다.
- 표정: 멋쩍으면서도 고마운 표정 → 다시 신나고 밝은 표정
- 대사: "그늘 잘 썼다봉, 고맙다봉!"
- 카메라: 정면 미디엄샷으로 인사 장면을 잡은 뒤, 부라봉이 몸을 돌려 걸어가는 것을 따라가는 후면 팔로우 샷으로 전환
- 자막: 화면 상단 안전 영역, "다음 그늘을 찾아서" (엔딩 자막, 부라봉 얼굴·이파리·볼을 가리지 않는 위치)
- 효과음: 잔잔한 숲 바람 소리와 멀어지는 발소리로 페이드 아웃 (사용 여부 미지정 — 담당자 확인 필요)
- 장면 전환: 페이드 아웃 (엔딩)
