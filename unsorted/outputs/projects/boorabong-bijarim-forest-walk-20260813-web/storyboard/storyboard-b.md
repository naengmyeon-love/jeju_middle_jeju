# 스토리보드 B안 — 코미디형

## 연출 방향

- 연출 콘셉트: 표정, 타이밍, 반전, 효과음을 강조한 연출
- 목표 감정: 웃음, 놀라움, 반전 재미
- 총 길이: 15초
- 장면 수: 4
- 카메라 성향: 클로즈업과 급격한 앵글 변화. 반전 장면에 시간을 몰아준다.
- 타이밍 재배분: 3 / 3 / 5 / 4초 — 앞을 빠르게 치고 3번째 장면의 정적을 길게 끈다.

## 장면별 이미지 보드

### 장면 1 · 00:00~00:03

> ⏳ **이미지 생성 대기**

- **스토리:** 얼굴만으로 더위를 전달한다. 첫 3초 안에 상황과 감정을 한 번에 던진다.
- **화면:** 얼굴이 화면을 가득 채우고 배경은 밝은 햇빛으로 단순화한다.
- **캐릭터:** 반쯤 감겨 처진 눈, 아래로 늘어진 갈매기 입. 눈 크기는 기본 정원을 유지한다.
- **대사·자막:** "여름은 진짜 못 참겠다봉…" / 하단 자막 + 상단 강조 자막 `녹는 중`
- **카메라:** 정면 클로즈업, 급격한 줌인 (영상용)
- **효과음·음악:** 크게 깔린 매미 소리, 열기 효과음 / 경쾌한 BGM
- **연결:** start-frame
- **끝 포즈:** 정면을 본 채 눈 뜨고 정지
- **영상 생성 프롬프트:** `prompts/b1.txt` 기반
- **이미지 생성 기록:** 정지 이미지 앵글 `front-facing close-up` / 레퍼런스 `page-08.png`, `page-09.png`, `page-10.png` / 모델 `nano_banana_pro`

### 장면 2 · 00:03~00:06

> ⏳ **이미지 생성 대기**

- **스토리:** 그늘에 들어서자마자 텐션이 최고로 뛴다. 뒤의 급정지와 낙차를 만들기 위한 장면이다.
- **화면:** 숲길 중간. 배경 요소를 줄여 캐릭터 동작에 시선을 모은다.
- **캐릭터:** 두 팔을 들고 공중에 뜬 순간. 꽉 감은 웃는 눈은 뜬 눈보다 가로로 조금 길게 그린다.
- **대사·자막:** "여기 완전 시원하다봉봉!" / 하단 자막 + 강조 자막 `뿅!`
- **카메라:** 정면 미디엄샷 (영상용)
- **효과음·음악:** 점프음, 새소리 / BGM 템포 상승
- **연결:** start-frame
- **끝 포즈:** 착지해 두 발로 선 채 정지 (공중 프레임으로 컷을 끝내지 않는다)
- **영상 생성 프롬프트:** `prompts/b2.txt` 기반
- **이미지 생성 기록:** 정지 이미지 앵글 `front-facing medium shot` / 레퍼런스 3장 동일 / 모델 `nano_banana_pro`

### 장면 3 · 00:06~00:11

> ⏳ **이미지 생성 대기**

- **스토리:** 5초를 통째로 정적에 쓴다. 소리를 끊고 크기 대비만 남겨 웃음을 만든다.
- **화면:** 거대한 비자나무가 화면 전체를 채우고 부라봉은 화면 아래 아주 작게 놓인다.
- **캐릭터:** 굳은 채 고개를 끝까지 젖히고 입을 크게 벌린다. 눈·입 상하 간격은 벌리지 않는다.
- **대사·자막:** 없음 / 화면 중앙 큰 자막 `…?!`
- **카메라:** 로우앵글 와이드샷 (영상용)
- **효과음·음악:** 급정지음 뒤 음악 정지, 정적 유지
- **연결:** start-frame
- **끝 포즈:** 굳은 자세 그대로 눈 뜨고 정지
- **영상 생성 프롬프트:** `prompts/b3.txt` 기반
- **이미지 생성 기록:** 정지 이미지 앵글 `low-angle wide shot` / 레퍼런스 3장 동일 / 모델 `nano_banana_pro`

### 장면 4 · 00:11~00:15

> ⏳ **이미지 생성 대기**

- **스토리:** 정적을 깨고 부라봉이 넙죽 인사한다. 낙차를 웃음으로 회수하고 끝낸다.
- **화면:** 나무 밑동 앞. 상반신 위주로 표정을 크게 보여준다.
- **캐릭터:** 눈을 감고 깊게 꾸벅 인사한다. 겸연쩍은 작은 갈매기 입.
- **대사·자막:** "…라봉이보다 몇 살 위냐봉?" / 하단 자막 + 강조 자막 `선배님`
- **카메라:** 정면 바스트샷 (영상용)

- **연결:** start-frame

- **영상 생성 프롬프트:** `prompts/b4.txt` 기반
