# 콘텐츠 기획안

## 기본 정보

- 콘텐츠 제목: 부라봉, 그늘 부자 되다봉
- 한 줄 요약: 더위에 지친 부라봉이 비자림 숲길을 걷다 수백 년 된 비자나무 앞에서 걸음을 멈추고 그 시원한 그늘에 폭 파묻혀버리는 코믹한 모습을 그린다.
- 제작 목적: 부라봉 단독 주인공 콘텐츠를 통해 캐릭터의 사고뭉치 같은 매력과 제주 자연 세계관을 확산한다.
- 예상 길이: 30초
- 장면 수: 5장면
- 화면 비율: 9:16
- 출력 해상도: 1080 × 1920
- 등장 캐릭터: 부라봉 (1인, 다른 캐릭터 등장 없음)
- 배경: 비자림 숲길 (구체적 구역 미지정 — 담당자 확인 필요)
- 핵심 감정: 즐거움·코믹
- 콘텐츠 유형: 일상 산책 + 코믹 리액션
- 생성 도구: Higgsfield
- 오디오: 미지정 (담당자 확인 필요)

## 스토리 구성

### 시작

한여름 더위에 이파리가 축 늘어진 부라봉이 시원한 숲길을 찾아 비자림 산책로 입구로 들어선다.

### 전개

숲의 서늘한 공기를 맞은 부라봉이 신이 나 산책로를 팔짝팔짝 뛰어다니며 여기저기 그늘을 기웃거리다가, 저 멀리 유난히 굵고 우람한 나무 한 그루를 발견하고 눈이 커진다.

### 핵심 포인트 또는 반전

수백 년 된 비자나무 앞에 딱 멈춰 선 부라봉이 밑동부터 우듬지까지 고개를 한껏 젖혀 올려다보다가, 그대로 나무 그늘 아래 대(大)자로 폭 파묻혀 버린다. 그늘이 너무 시원한 나머지 스르르 눈이 감기려는 찰나, 화들짝 놀라 정신을 차리는 코믹한 리액션을 보인다.

### 마무리

부라봉이 벌떡 일어나 나무를 향해 꾸벅 인사하고, 다시 신나는 발걸음으로 숲길을 걸어가는 뒷모습으로 마무리한다.

## 장면 개요

1. **0–6초 — 훅:** 비자림 숲길 입구. 더위에 지쳐 이파리가 축 처진 부라봉이 걸어 들어오다 시원한 공기에 눈이 번쩍 뜨인다.
2. **6–12초 — 전개:** 산책로 곳곳. 부라봉이 신이 나 팔짝팔짝 뛰어다니며 그늘을 이곳저곳 기웃거린다.
3. **12–18초 — 발견:** 부라봉이 저 멀리 유난히 굵고 우람한 나무를 발견하고 눈이 커지며 걸음을 멈춘다.
4. **18–24초 — 반전(핵심 포인트):** 수백 년 된 비자나무 밑동부터 우듬지까지 고개를 젖혀 올려다보다가, 그대로 그늘 아래 대(大)자로 파묻혀 스르르 눈이 감기려 한다.
5. **24–30초 — 마무리:** 화들짝 놀라 정신을 차리고 벌떡 일어난 부라봉이 나무에 꾸벅 인사한 뒤 다시 신나게 숲길을 걸어간다.

## 제작 요소

- 주요 대사: 구체적 대사·자막 문구는 담당자가 제공하지 않아 미정이다. 다음 단계(시나리오 작성)에서 확정하며, 확정 시 부라봉 공식 어미(`~다봉`/`~라봉`/`~냐봉`/`~다봉봉`)를 반드시 따른다. (담당자 확인 필요)
- 주요 행동: 더위에 지쳐 걷다가 시원함에 신나 뛰어다니기 / 거대한 비자나무를 발견하고 올려다보기 / 그늘에 대자로 파묻히기 / 졸다가 화들짝 깨기 / 나무에 인사하고 다시 걷기
- 필요한 배경: 비자림 숲길 산책로와 수백 년 된 굵은 비자나무 그늘 (구체적 촬영 구역은 미지정 — 담당자 확인 필요)
- 필요한 소품: 없음 (신규 소품 없이 부라봉의 공식 기본 외형만 사용한다)
- 효과음: 미지정 (담당자 확인 필요)
- 배경음악 분위기: 미지정 (담당자 확인 필요)
- 화면 자막: 자막 문구는 미정이며 시나리오 단계에서 확정한다. 사용 시 화면 상단 또는 하단 안전 영역에 배치하고 부라봉의 얼굴·꼭지 이파리·볼을 가리지 않는다.
- Higgsfield 설정: 캐릭터 이미지 생성 시 부라봉 공식 레퍼런스 페이지(소개 p08, 턴어라운드 p09, 사용 규칙 p10)를 반드시 첨부하고 `image_generation.characters.boo-rabong.lock_en` 문자열을 변형 없이 그대로 사용한다. 장면별 이미지 생성 후 이미지-투-비디오 방식을 권장하며, `sound` 설정은 오디오 방침이 확정된 뒤 결정한다(현재 미지정).

## 비주얼 고정 규칙

- 부라봉은 주황 한라봉 몸체, 초록 꼭지와 이파리(좌우 위치 모두 허용), 양쪽 큰 진한 주황 볼, 흰색 하의를 유지한다.
- 기본 눈은 정원이며 세로눈을 사용하지 않고, 지정된 감정 변형 외에는 눈 크기를 키우거나 줄이지 않는다.
- 윗입술은 뒤집힌 갈매기(3자) 형태를 유지하고, 입 가운데가 뾰족해지지 않게 한다.
- 눈과 입의 상하 간격이 벌어지지 않게 하고, 1.5등신 비율을 유지한다.
- 옆모습에서 꼭지는 중심에서 살짝 뒤로 기운 형태를 유지한다.
- 장면마다 정면·측면·후면 형태가 공식 턴어라운드(p09)와 일치해야 한다.
- 공식 HEX 값은 미확보 상태이므로 임의의 색상 코드를 사용하지 않고 서술형 색상 지시만 사용한다.
- 이미지 안에 대사·자막·말풍선·로고·워터마크를 넣지 않는다.
- 공식 6인 외 캐릭터(고르방, 양퐁당, 냥냥이, 호꼬, 구애구 포함)를 등장시키지 않는다.

## 검수 항목

- 캐릭터 가이드 준수: 부라봉의 한라봉 모티브·사고뭉치 정체성과 공식 어미(`~다봉`/`~라봉`/`~냐봉`)를 반영했다. 기억상실 이전 과거는 사실로 확정하지 않았다. 등장 캐릭터를 부라봉 1인으로 제한했다.
- 세계관 가이드 준수: 비자림은 공식 배경 목록(고르방의 집, 할머니의 귤밭)에 없는 확장 배경이므로 확인 필요 항목으로 표시했다. 다른 캐릭터가 등장하지 않아 공식 관계 극성(§5)을 훼손할 소지가 없다.
- 직접적 상업성 노출 여부: 없음
- 저작권 위험 요소: 배경음악·효과음 사용 여부가 미확정이므로 사용을 결정할 경우 저작권이 확인된 음원만 사용해야 한다. 비자림의 실제 안내판·표지판 등 시설물은 사실적으로 재현하지 않는다.
- 담당자 확인 필요:
  1. 비자림 배경의 사용 허용 범위와 구체적 촬영 구역
  2. 대사 및 화면 자막 문구
  3. 배경음악·효과음 사용 여부와 분위기
  4. 게시 예정 플랫폼
  위 항목은 모두 다음 단계(시나리오·스토리보드) 진행 전 확정이 필요하다.
- 예상 수정 사항: Higgsfield 생성 시 부라봉의 눈·입·이파리·볼 형태와 대자로 파묻힌 포즈의 신체 비율이 흔들릴 수 있으므로 장면별 대표 프레임 검수가 필요하다.
