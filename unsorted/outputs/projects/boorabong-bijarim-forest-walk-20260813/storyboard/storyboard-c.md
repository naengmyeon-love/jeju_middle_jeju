## 장면별 구성

### 장면 1 — 잎사귀 발견 (0-3초)

| 요소 | 내용 |
|---|---|
| 화면 | 비자림 숲길. 부라봉이 걷다가 반짝이는 비자나무 잎사귀에 시선이 멈춘다. 잎사귀가 프레임 한 켠에 반짝임 |
| 카메라 | 부라봉 전경, 잎사귀는 배경에서 반짝임. 부라봉의 시선이 잎사귀를 향함 |
| 부라봉 표정 | 눈이 반짝이며 동그래짐. "탐스럽다"는 느낌의 호기심 가득한 표정 |
| 대사 | "와 저거 완전 탐스럽다봉! 저 잎사귀 갖고 싶다봉!" |
| 자막 | "탐나는 잎사귀 ✨" |
| 사운드 | 발견의 효과음 + BGM 시작 |

### 장면 2 — 잎사귀 따라가기 (3-6초)

| 요소 | 내용 |
|---|---|
| 화면 | 바람에 잎사귀가 날아간다. 부라봉이 "잠깐만!" 하며 따라간다. 부라봉의 짧은 팔다리로 열심히 뛰는 코믹한 모습 |
| 카메라 | 부라봉의 움직임을 따라가는 핸드헬드 느낌 또는 부라봉 중심 추적 샷 |
| 부라봉 표정 | 열심히 쫓는 표정. 약간 당황 + 결의에 찬 눈 |
| 대사 | "잠깐만! 거기 서라봉! 왜 자꾸 도망가냐봉!" |
| 자막 | "잡히지 않는 잎사귀 🍃" |
| 사운드 | 바람이 불어오는 효과음 + 부라봉 뛰어가는 경쾌한 효과음 + BGM 경쾌 |

### 장면 3 — 허무한 추적 (6-9초)

| 요소 | 내용 |
|---|---|
| 화면 | 부라봉이 열심히 뛰지만 잎사귀는 계속 멀어진다. 부라봉이 프레임 왼쪽으로 치우치고 잎사귀는 오른쪽으로 날아감 |
| 카메라 | 부라봉과 잎사귀의 거리감을 보여주는 구도. 또는 부라봉 클로즈업 + 잎사귀는 배경에서 작게 |
| 부라봉 표정 | 점점 당황 + 허탈. 눈이 약간 아래로 향함. 입이 갈매기 형태 유지하되 약간 풀림 |
| 대사 | "하... 왜 자꾸 멀어지냐봉? 나랑 놀아주면 안 되냐봉..." |
| 자막 | "안 잡혀요ㅠㅠ" |
| 사운드 | 허무한 효과음 + BGM 살짝 코믹하게 |

### 장면 4 — 포기 + 웃음 (9-12초)

| 요소 | 내용 |
|---|---|
| 화면 | 부라봉이 멈춰 서서 머쓱하게 웃는다. 잎사귀는 화면 밖으로 사라짐. 부라봉이 혼자 남은 구도 |
| 카메라 | 부라봉 클로즈업 또는 반신. 배경의 숲은 고요함 |
| 부라봉 표정 | 머쓱한 웃음. 눈이 살짝 감기고 갈매기 입이 흐물흐물 (코믹). 볼이 약간 붉어질 수 있음 |
| 대사 | "하... 역시 난 안 되나봉ㅋㅋ 잎사귀야 다음에 보자봉..." |
| 자막 | "머쓱ㅋㅋㅋ" |
| 사운드 | 머쓱한 웃음 효과음 + BGM 코믹하게 전환 |

### 장면 5 — 마무리 (12-15초)

| 요소 | 내용 |
|---|---|
| 화면 | 부라봉이 다시 숲길을 걸으며 만족한 표정. 잎사귀가 다시 반짝이며 등장해도 좋음 (희망적 결말) |
| 카메라 | 부라봉 전신. 숲길 배경. 하단 중앙 로고 |
| 부라봉 표정 | "그래도 재밌었다"는 만족감. 미소, 눈이 반짝임 |
| 대사 | "그래도 재밌었다봉~ 숲 산책 최고다봉! 다음에 또 오겠다봉!" |
| 자막 | "비자림 숲길 산책 🌲" + 로고 |
| 사운드 | BGM 경쾌하게 마무리 + 자연 잔향 |

## 캐릭터 외형 체크리스트 (장면별)

| 장면 | 눈 | 입 | 잎사귀 위치 | 볼 | 비고 |
|---|---|---|---|---|---|
| 1 | 반짝이며 동그랗게 | 갈매기 살짝 벌어짐 | (배경 반짝임) | 진한 주황 | 발견 |
| 2 | 결의에 찬 눈 | 갈매기 다문 | (부라봉 손x, 잎사귀는 바람에) | 진한 주황 | 추적 |

| 5 | 반짝, 미소 | 갈매기 미소 | (재등장 가능) | 진한 주황 | 만족 |

## 기술 노트

- **프레임**: 1080×1920 (9:16)
- **길이**: 총 15초 (장면당 약 3초)
- **잎사귀 표현**: 비자나무 잎사귀의 실제 모양. 반짝임/바람 효과. 프레임 내에서 자연스럽게 움직임
- **부라봉 움직임**: 짧은 팔다리 스터브로 뛰는 코믹한 움직임. 손·발가락 없음.
- **색감**: 초록 숲 + 반짝이는 잎사귀 + 주황 부라봉
- **코믹 포인트**: 장면 3-4의 허무 → 장면 5의 긍정 회복

## Claude Code 검수 반영 (2026-08-13)

- 장면 1 "반짝이며 동그랗게"는 `image-generation-contract.json`의 "반짝이는 눈은 평소보다 살짝 큼"과 일치. 눈 크기를 그 이상으로 키우라는 지시가 없어 위반 아님.
- 장면 4 "살짝 감김"은 "반만 감은 눈" 허용 변형과 부합.
- 장면 2·3의 시선 방향(결의/당황) 묘사는 눈 형태 자체를 바꾸는 지시가 아니므로 위반 아님.
- 수정 사항 없음. 배경(비자림) 사용은 다른 두 기획안·스토리보드와 동일하게 담당자 확인 필요 상태다.
