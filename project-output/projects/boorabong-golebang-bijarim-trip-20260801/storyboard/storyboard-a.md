# 스토리보드 A안 — 기본형

## 연출 방향

- 연출 콘셉트: 캐릭터와 대사가 명확하게 전달되는 안정적 연출
- 목표 감정: 편안함, 이해 용이
- 총 길이: 30초
- 장면 수: 5

| 장면 | 시간 | 화면 구성 | 캐릭터 행동·표정 | 대사·자막 | 카메라 | 효과음·음악 | 생성 프롬프트 |
|---|---:|---|---|---|---|---|---|

| 4 | 18~24초 | 같은 나무 아래, 조금 더 가까운 위치. | 부라봉이 자기 이파리를 만지작거리며 기대에 차 묻다가 어깨를 늘어뜨리고 시무룩해진다. 고르방이 미안한 듯 웃는다. | 부라봉 "라봉이도 이만큼 커지냐봉?" → 고르방 "라봉이는 나무가 아니라 과일이잖아~" / 하단 중앙 자막, 순차 표시 | 부라봉 정면 클로즈업 → 미디엄 샷 | 없음 | 동일한 공식 외형. 부라봉의 반쯤 감은 눈과 처진 어깨, 윗입술 뒤집힌 갈매기 형태 유지. 새 소품 없음, 텍스트 없음. |
| 5 | 24~30초 | 비자림 산책로, 부드러운 햇빛. | 고르방이 몸을 숙여 한마디를 건네고, 부라봉이 두 팔을 번쩍 들며 활짝 웃는다. | 고르방 "대신 우주 최고 명품 과일이 될 거잖아." → 부라봉 "지켜봐주라봉~!" / 하단 중앙 자막, 순차 표시 | 3/4 미디엄 샷 → 와이드로 후퇴 | 없음 | 동일한 공식 외형과 캐릭터 비례. 고르방이 더 큼, 부라봉 흰색 하의 유지. 텍스트·로고·워터마크 없음. |

## 장면별 이미지 보드

### 장면 1 · 00:00~00:05

![A안 장면 1 — 비자림 숲길로 뛰어 들어가는 부라봉](images/a/scene-01.png)

- **스토리:** 더위를 많이 타는 부라봉이 시원한 비자림 숲 공기에 신이 나 앞장서 뛰어 들어간다.
- **화면:** 비자림 입구, 붉은 화산송이 산책로와 이끼 낀 비자나무 군락.
- **캐릭터:** 부라봉은 활짝 웃으며 달리고, 고르방은 뒤에서 여유롭게 걸어온다.
- **대사·자막:** "여긴 완전 시원하다봉!" / 상단
- **카메라:** 세로 와이드 정면 고정 샷
- **효과음·음악:** 없음
- **영상 생성 프롬프트:** 위 표의 장면 1 프롬프트 참조.
- **이미지 생성 기록:** Higgsfield Nano Banana 2(`nano_banana_flash`), 공식 페이지 08·09·10·11·12·13 + 페이지 07 캐릭터 크롭 참조.

### 장면 2 · 00:05~00:11

![A안 장면 2 — 나무를 가리키며 수다를 떠는 고르방](images/a/scene-02.png)

- **스토리:** 고르방이 수백 년 된 비자나무를 올려다보며 아재개그를 던지고, 부라봉은 반응이 시큰둥하다.
- **화면:** 숲길 한가운데, 이끼 낀 굵은 기둥들.
- **캐릭터:** 고르방은 손을 들어 가리키며 흐뭇하게 웃고, 부라봉은 고개를 갸웃한다.
- **대사·자막:** "비자림엔 비자가 필요 없지~ 하하" / 하단
- **카메라:** 미디엄 정면 샷
- **효과음·음악:** 없음
- **영상 생성 프롬프트:** 위 표의 장면 2 프롬프트 참조.
- **이미지 생성 기록:** 동일 레퍼런스 + 장면 1 이미지 참조.
- **검수 메모:** 고르방의 눈이 눈썹만 남고 누락됐다. 영상 생성 전 재생성 필요.

### 장면 3 · 00:11~00:18

![A안 장면 3 — 거대한 비자나무를 올려다보는 부라봉](images/a/scene-03.png)

- **스토리:** 가장 굵은 비자나무 앞에서 부라봉의 감탄이 최고조에 달한다.
- **화면:** 이끼로 덮인 거대한 기둥과 쏟아지는 빛줄기.
- **캐릭터:** 부라봉은 눈을 반짝이며 올려다보고, 고르방은 뒤에서 흐뭇하게 바라본다.
- **대사·자막:** 없음
- **카메라:** 슬로우 틸트 업 → 로우 앵글 와이드
- **효과음·음악:** 없음
- **영상 생성 프롬프트:** 위 표의 장면 3 프롬프트 참조.
- **이미지 생성 기록:** 동일 레퍼런스 + 장면 1 이미지 참조.
- **검수 메모:** 부라봉의 흰색 하의가 누락되고 고르방의 눈이 빠졌다. 영상 생성 전 재생성 필요.

### 장면 4 · 00:18~00:24

![A안 장면 4 — 시무룩해진 부라봉](images/a/scene-04.png)

- **스토리:** 부라봉이 자기도 나무처럼 커질 거라 기대했다가 "과일"이라는 답에 시무룩해진다.
- **화면:** 같은 나무 아래, 조금 더 가까운 위치.
- **캐릭터:** 부라봉은 어깨를 늘어뜨리고 반쯤 감은 눈, 고르방은 미안한 듯 웃는다.
- **대사·자막:** "라봉이도 이만큼 커지냐봉?" → "라봉이는 나무가 아니라 과일이잖아~" / 하단, 순차
- **카메라:** 정면 클로즈업 → 미디엄 샷
- **효과음·음악:** 없음
- **영상 생성 프롬프트:** 위 표의 장면 4 프롬프트 참조.
- **이미지 생성 기록:** 동일 레퍼런스 + 장면 1 이미지 참조.
- **검수 메모:** 고르방의 눈이 누락됐고, 부라봉의 입이 공식 뒤집힌 갈매기 형태에서 벗어난 덩어리 형태로 표현됐다. 재생성 필요.

### 장면 5 · 00:24~00:30

![A안 장면 5 — 다시 신이 난 부라봉과 고르방](images/a/scene-05.png)

- **스토리:** 고르방의 응원에 부라봉이 다시 활짝 웃으며 자기 꿈을 외친다.
- **화면:** 비자림 산책로, 부드러운 햇빛.
- **캐릭터:** 부라봉은 눈을 감고 활짝 웃고, 고르방은 인자하게 바라본다.
- **대사·자막:** "대신 우주 최고 명품 과일이 될 거잖아." → "지켜봐주라봉~!" / 하단, 순차
- **카메라:** 3/4 미디엄 샷 → 와이드 후퇴
- **효과음·음악:** 없음
- **영상 생성 프롬프트:** 위 표의 장면 5 프롬프트 참조.
- **이미지 생성 기록:** 동일 레퍼런스 + 장면 1 이미지 참조.
- **검수 메모:** 고르방의 눈이 누락됐다. 재생성 필요.
