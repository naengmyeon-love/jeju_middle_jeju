# 스토리보드 A — 부라봉, 잎사귀 착각 소동 (기본 코믹형)

> 이 스토리보드는 Solar Pro 4가 텍스트 문안 단계까지만 작성한 초안이다. 캐릭터 가이드 적용·준수 판정은 포함하지 않으며, 채택 확정은 Claude Code 검토 전이므로 미채택으로 기록한다.
> 이미지 생성은 이 smoke test에서 금지하므로, 장면 설명은 문안/구도 중심으로만 적는다.

## 기본

- 안: A안(기본 코믹형)
- 길이: 15초
- 비율: 9:16
- 캐릭터: 부라봉
- 감정: 즐거움 · 코믹
- 범위: 기획 문안까지만. 이미지·영상·외부 배포 없음.

## 장면별 문안

### 장면 1 — establishing (0:00~0:03)

- 내용: 마당에서 쉬고 있는 부라봉. 안정적 첫 인상.
- 구도: 화면 중앙 근처, 세로 프레임에 부라봉이 comfortably 잡힘.
- 표정: 편안한 휴식.
- 자막: 없음.
- 소리: 잔잔한 환경음.

### 장면 2 — 잎사귀 날아감 (0:03~0:06)

- 내용: 바람이 불어 잎사귀 하나가 휙 날아감.
- 구도: 잎사귀가 프레임 위를 지나가며 시선 유도.
- 표정: 부라봉 고개 들기, 살짝 놀람.
- 자막(후보): "어…?"
- 소리: 바람 스침.

### 장면 3 — 착각 강조 (0:06~0:09)

- 내용: 부라봉이 머리 위를 더듬으며 자기 잎이 사라졌다고 느낌.
- 구도: 클로즈업으로 표정 강조.
- 표정: 당황, 코믹.
- 자막(후보): "내 잎…?"
- 소리: 짧은 코믹 반응음.

### 장면 4 — 거울 확인 (0:09~0:12)

- 내용: 거울/반사면을 보고 확인, 그대로임을 눈치챔.
- 구도: 거울이 보이는 구도로 대칭/반전 느낌.
- 표정: 의아 → 확인.
- 자막(후보): "그대로네?"
- 소리: 확인 느낌의 짧은 음.

### 장면 5 — 머쓱 마무리 (0:12~0:15)

- 내용: 머쓱하게 웃으며 끝.
- 구도: 부라봉 표정 클로즈업.
- 표정: 머쓱한 웃음.
- 자막(후보): "머쓱…"
- 소리: 가벼운 웃음/바람 잔향.

## 안별 차별점

- A안은 클래식한 코믹 흐름: 당황 → 확인 → 머쓱.
- 이미지 없이 문안/구도만 제공하며, 채택은 Claude Code 검토 전 미채택.
