# 스토리보드 A안 — 기본형

> **일러두기 (담당자 확인 전 임시안)**
> planning/scenario.md에서 "담당자 확인 필요"로 표시된 항목(대사, 자막, 배경음악, 효과음, 비자림 구체 촬영 구역)은 이 문서에서도 임시안을 그대로 유지한다. 확정 전까지 촬영·생성에 참고용으로만 사용한다.

## 연출 방향

- 연출 콘셉트: 캐릭터와 대사가 명확하게 전달되는 안정적 연출. 정면·중간 샷 위주로 부라봉의 상태 변화(지침 → 시원함 → 압도됨)를 순서대로 또박또박 보여준다.
- 목표 감정: 편안함, 이해 용이
- 총 길이: 15초
- 장면 수: 3장면 (scenario.md의 3장면 구성을 그대로 따름)

## 장면별 이미지 보드

### 장면 1 · 00:00~00:05

**이미지 생성 대기 — 아래 "이미지 생성 기록" 참고**

- **스토리:** 뜨거운 볕 아래 지친 부라봉이 비자림 숲길로 들어선다. 그늘 안쪽에 발을 들이는 순간 서늘한 공기를 느끼고 표정이 확 밝아지며, 다음 장면에서 신나게 뛰는 이유가 만들어진다.
- **화면:** 비자림 숲길 입구. 볕이 드는 산책로가 그늘진 숲 안쪽으로 이어지는 지점(구체 촬영 구역은 담당자 확인 필요).
- **캐릭터:** 이파리가 축 늘어진 채 터벅터벅 걷던 부라봉이 그늘에 들어서는 순간 눈이 반짝이며 번쩍 뜨인다(정원 유지, 허용된 반짝임 변형).
- **대사·자막:** "더워서 축 늘어지겠다봉..." → "어? 시원하다봉!" / 상단 안전 영역, "무더위 속, 그늘을 찾아서" (얼굴·꼭지 이파리·볼 미가림)
- **정지 이미지 순간(선택 근거):** 두 순간(지침/반짝임) 중 그늘 진입과 동시에 일어나는 표정 전환 한 순간만 선택했다. "then"류 시간 흐름 표현 없이 한 컷으로 성립하는 전환점이다.
- **카메라(정지 이미지용):** `front-facing full shot` (앵글 1개 + 샷 크기 1개, 이동·전환 표현 없음)
- **효과음·음악:** 여름 매미 울음, 터벅이는 발걸음 → 그늘 진입 시 청량한 바람 소리로 전환
- **영상 생성 프롬프트(참고 초안):** 위 연출 요약표 1행 참고. 정지 이미지 프롬프트와는 별도이며, 실제 영상화 시 재조립 필요.
- **이미지 생성 기록:**
  - 레퍼런스: `shared/references/pages/page-08.png`(부라봉 소개), `page-09.png`(턴어라운드), `page-10.png`(사용 규칙) — `view_image`로 직접 확인함.
  - 조립 도구: `node unsorted/scripts/build-pongdang-prompt.mjs`(higgsfield-prompt-builder 스킬의 조립 스크립트). 손으로 쓴 프롬프트 아님.
  - 정지 이미지 입력 게이트: 통과 (샷 1개 `full shot`, 시간 흐름·전환 표현 없음, 네거티브 16항목 포함).
  - 조립된 프롬프트:
    ```
    [STYLE]
    flat 2D Korean kawaii mascot illustration, thick uniform dark-brown outline, flat fill colours with no gradient shading, simple rounded shapes, plain background, official character-sheet style

    [CAST]
    BOO RABONG: orange Hallabong citrus character, round citrus head fused with the body, one green leaf sprig on top of the head, two large round orange blush cheeks, base eyes are perfect circles, upper lip is an upside-down seagull curve (three-stroke shape), small pale-yellow tongue, white diaper-like lower garment, short stubby limbs, about 1.5 head-to-body proportion, front view wider than side view, small gap between eyes and mouth

    [SCENE]
    BOO RABONG steps from a sun-lit trail into forest shade, tired drooping eyes suddenly opening wide and sparkling with relief, mouth in a small delighted curve.
    Background is a forest trail where a sunlit path meets shaded trees under tall trunks.

    [COMPOSITION]
    front-facing full shot, vertical 9:16 framing, the single character inside the safe area, plain uncluttered background
    one single uninterrupted frame filling the whole canvas, one camera angle, one moment in time

    [NEGATIVE]
    (global_negative_en 9항목 + boo-rabong forbidden_en 7항목, 총 16항목 — contract v1.1 기준)

    [OUTPUT]
    single still image, one frame only, no text anywhere in the image
    ```
  - 실행 명령: `higgsfield generate create nano_banana_flash --prompt '...' --image 'shared/references/pages/page-08.png' --image 'shared/references/pages/page-09.png' --image 'shared/references/pages/page-10.png' --aspect_ratio 9:16 --resolution 2k --wait`
  - **생성 미실행 사유:** ① `unsorted/outputs/projects/boorabong-bijarim-forest-walk-20260811-15s/metadata/production-log.json`의 `approvals.production.status`가 `not_requested`로, 제작·비용 승인이 아직 기록되지 않았다(higgsfield-prompt-builder 사전 게이트 항목 "유료 호출이면 제작·비용 승인이 기록되어 있는가" 미충족). ② 이번 세션에서 `higgsfield` CLI 직접 호출이 권한 정책상 차단되어(`This command requires approval`) 실제 API 호출 자체가 불가능했다. 프롬프트 조립까지는 완료했고 재생성 가능 여부는 "가능 — 제작·비용 승인 및 CLI 실행 권한 확보 후 위 명령을 그대로 실행"이다.

- **카메라(정지 이미지용):** `three-quarter view medium shot`
- **효과음·음악:** 숲속 새소리, 나뭇잎 스치는 소리, 통통 튀는 발걸음 → 시선 멈추는 순간 효과음 잦아듦
- **영상 생성 프롬프트(참고 초안):** 위 연출 요약표 2행 참고.
- **이미지 생성 기록:**
