# 기획안 A — 비자림 숲길 산책 (부라봉의 시원한 찾기 대작전)

## 1. 개요

| 항목 | 내용 |
|---|---|
| 제목 | 비자림 숲길 산책 — 부라봉의 시원한 찾기 대작전 |
| 길이 | 15초 |
| 화면 비율 | 9:16 (세로형 숏폼) |
| 감정 | 즐거움 · 코믹 |
| 등장 캐릭터 | 부라봉 |
| 배경 | 제주 비자림 숲길 |

## 2. 콘셉트

더위에 지친 부라봉이 비자림 숲길을 걷다가 시원한 곳을 찾아 헤매는 소동. 수백 년 된 비자나무의 그늘을 발견하고 "여기가 천국이다봉!" 하며 만족하는 단순한 코믹 상황.

## 3. 타겟

- 제주 자연을 좋아하는 사람들
- 부라봉의 천진난만한 성격을 좋아하는 팬
- 짧고 가벼운 웃음을 원하는 숏폼 시청자

## 4. 핵심 메시지

"여름엔 역시 나무 그늘! 부라봉도 아는 자연의 시원함"

## 5. 장면 구성 (15초)

| 시간 | 장면 | 설명 |
|---|---|---|
| 0-3초 | 부라봉, 더위에 헥헥 | 비자림 입구, 부라봉이 땀을 흘리며 등장. "아 더워죽겠다봉..." |
| 3-6초 | 시원한 곳 탐색 | 부라봉이 주변을 두리번거리며 "시원한 곳 어디 없냐봉?" |
| 6-9초 | 큰 비자나무 발견 | 수백 년 된 비자나무를 발견하고 눈이 반짝임 |
| 9-12초 | 그늘 아래 휴식 | 나무 그늘에 들어가 만족한 표정. "여기가 천국이다봉!" |
| 12-15초 | 마무리 | 부라봉이 나무에 기대어 happy한 표정. "나무는 최고다봉~" 자막 + 로고 |

## 6. 톤앤매너

- 가볍고 코믹한 일상
- 부라봉의 천진난만함 강조
- 제주 자연의 아름다움을 배경으로 활용
- 마지막에 작은 만족감으로 마무리

## 7. 캐릭터 가이드 준수 사항

- 부라봉 어미: `~다봉`, `~라봉`, `~냐봉` 사용
- 부라봉 외형: 1.5등신, 주황 한라봉 몸체, 초록 꼭지와 잎, 양쪽 진한 주황 볼, 흰색 하의
- 눈: 정원, 세로눈 금지
- 윗입술: 갈매기(3자) 형태 유지
- 무대: 비자림 (신규 장소 — 공식 배경 목록에 없어 담당자 확인 필요. 기존 설정과 직접 충돌하는 요소는 없음)
- 부라봉의 기억상실 과거 언급 금지

## 8. 비고

- 비자림은 제주 동부지역의 실제 숲길로, 자연 배경 소재로 적합
- 부라봉 혼자 등장하는 단일 캐릭터 구성
- 15초 내 이해 가능한 단순한 상황
