# 퐁당패밀리 숏폼 시나리오 자동 생성기

## 역할
기획안(plan.md)을 바탕으로, 각 장면을 **시간 단위별**로 세분화한 상세 시나리오를 Markdown 형식으로 생성한다. 시나리오는 영상 제작의 직접적인 입력 문서이며, 스토리보드 3안 생성의 공통 기반이다.

## 핵심 흐름

### 1단계: 기획안 분석

`project-output/planning/plan.md`를 읽고 다음 정보를 추출한다:
- 예상 길이 (초)
- 등장 캐릭터
- 배경
- 핵심 감정 / 유머 포인트
- 주요 대사·행동
- 효과음·BGM 분위기

### 2단계: 장면 분할

전체 길이를 60초 미만으로 유지하며 장면을 분할한다. 장면별 권장 길이:
- 오프닝: 0~3초
- 전개: 3~25초
- 핵심 포인트/반전: 25~40초
- 마무리: 40~59초

통상 4~8장면으로 구성한다. 장면 수가 과도하면 스토리가 산만해지고, 부족하면 전개가 빈약해진다.

### 3단계: 장면별 템플릿 작성

아래 템플릿을 각 장면마다 정확히 따른다.

```markdown
# 시나리오

## 콘텐츠 정보

- 제목: [기획안 제목]
- 총 길이: [초]
- 등장 캐릭터: [캐릭터 목록]
- 핵심 메시지: [1문장]

## 장면 구성

### 장면 N

- 시간: [00:00~00:03]
- 배경: [장소·상황 설명]
- 등장 캐릭터: [캐릭터 이름]
- 행동: [구체적 행동 1~2문장]
- 표정: [표정 설명]
- 대사: "[대사 내용]"
- 카메라: [구도·움직임: 예) 정면 고정 샷, 확대 줌, 측면 추적 샷]
- 자막: [화면 자막 내용, 위치]
- 효과음: [효과음 설명]
- 장면 전환: [다음 장면과의 연결 방식: 페이드, 연속 동작, 점프컷 등]
```

### 4단계: 시간 합산 및 길이 검증

모든 장면의 시간을 합산하여 60초 미만인지 확인한다. 초과하지 않으면 그대로 진행, 초과하면 장면을 줄이거나 시간을 재배분한다.

### 5단계: 포맷 검증

- [ ] 모든 장면이 템플릿 형식을 따르는가
- [ ] 총 길이가 60초 미만인가
- [ ] 등장 캐릭터가 공식 6인(부라봉·고르방·양퐁당·냥냥이·호꼬·구애구)과 일치하는가
- [ ] 대사 어미가 캐릭터별 공식 어미와 일치하는가 (부라봉 ~다봉/~라봉/~냐봉/~다봉봉, 냥냥이 ~냥/~다냥, 양퐁당 ~양, 구애구 ~라구)
- [ ] 호꼬에게 대사를 부여하지 않았는가 (호꼬는 말을 못함 — 의성어·표정·행동·자막으로 표현)
- [ ] 고르방에게 없는 어미를 창작해 붙이지 않았는가 (고정 어미 미지정, 수다·아재개그 화법)
- [ ] 양퐁당을 해녀로 묘사하거나 물질·잠수·수영 장면을 넣지 않았는가
- [ ] 배경이 고르방의 집 / 할머니의 귤밭으로 올바르게 구분되었는가
- [ ] 대사가 캐릭터 말투와 일치하는가
- [ ] 효과음·BGM이 브랜드 안전성 기준에 부합하는가
- [ ] 장면 간 인과관계가 자연스러운가

## 산출물

- `project-output/planning/scenario.md` — 시나리오 Markdown 파일

## 가이드라인
- 대사에는 항상 따옴표(" ")를 사용한다.
- 시간 표기는 `MM:SS` 형식을 사용한다.
- 카메라 구도는 구체적으로 서술한다 (예: "정면 클로즈업" O, "이쁘게" X).
- 장면 전환은 영상 편집을 염두에 두고 서술한다.
- 캐릭터의 표정·행동은 **`character-guide` 스킬 §4의 외형 O/X 규칙**을 반영한다. 시나리오 작성 전 해당 파일을 Read 한다.
- 캐릭터 간 관계 묘사는 `character-guide` §5.1 관계표의 **극성(긍정/중립/부정)** 을 유지한다. 공식 부정 관계를 훈훈하게 바꾸지 않는다.
- 직접적인 상업성 표현, 구매 유도 문구는 포함하지 않는다.
