# 기획안 C — 비자림 숲길 산책 (부라봉의 잎사귀 짝사랑)

## 1. 개요

| 항목 | 내용 |
|---|---|
| 제목 | 비자림 숲길 산책 — 부라봉의 잎사귀 짝사랑 |
| 길이 | 15초 |
| 화면 비율 | 9:16 (세로형 숏폼) |
| 감정 | 즐거움 · 코믹 |
| 등장 캐릭터 | 부라봉 |
| 배경 | 제주 비자림 숲길 |

## 2. 콘셉트

부라봉이 비자림을 걷다가 반짝이는 비자나무 잎사귀를 발견하고 "저 잎사귀 완전 탐스럽다봉!" 하며 따라가려는 귀여운 상황. 잎사귀가 바람에 날아 부라봉이 허무하게 쫓아가다 결국 포기하며 웃는 코믹 결말.

## 3. 타겟

- 부라봉의 순수하고 엉뚱한 행동을 좋아하는 팬
- 귀여운 동물 캐릭터의 짝사랑 코드에 공감하는 시청자
- 짧고 가벼운 코미디를 원하는 숏폼 시청자

## 4. 핵심 메시지

"부라봉의 호기심과 천진난만함이 만들어 내는 작은 소동"

## 5. 장면 구성 (15초)

| 시간 | 장면 | 설명 |
|---|---|---|
| 0-3초 | 비자림 산책 중 | 부라봉이 숲길을 걷다가 반짝이는 잎사귀를 발견. 눈이 반짝임 "와 저거 완전 탐스럽다봉!" |
| 3-6초 | 잎사귀 따라가기 | 바람에 잎사귀가 날아감. 부라봉이 "잠깐만! 거기 서라봉!" 하며 따라감 |
| 6-9초 | 허무한 추적 | 부라봉이 열심히 쫓아가지만 잎사귀는 계속 날아감. "왜 자꾸 멀어지냐봉..." |
| 9-12초 | 포기 + 웃음 | 결국 잎사귀를 놓치고 머쓱하게 웃음. "하... 역시 난 안 되나봉ㅋㅋ" |
| 12-15초 | 마무리 | 부라봉이 숲길을 다시 걸으며 "그래도 재밌었다봉~" 하고 만족. 자막 + 로고 |

## 6. 톤앤매너

- 부라봉의 천진난만한 호기심을 살린 코믹 소동
- 작은 좌절과 빠른 회복으로 유쾌함
- 제주 자연의 아름다움 속 작은 사건
- 마지막에 긍정 에너지로 마무리

## 7. 캐릭터 가이드 준수 사항

- 부라봉 어미: `~다봉`, `~라봉`, `~냐봉`, `~다봉봉` 사용
- 부라봉 외형: 1.5등신, 주황 한라봉 몸체, 초록 꼭지와 잎, 양쪽 진한 주황 볼, 흰색 하의
- 눈: 정원, 반짝이는 눈은 평소 눈보다 살짝 크게 허용
- 윗입술: 갈매기(3자) 형태 유지
- 부라봉의 특징 활용: 호기심 많음, 변덕, 남의 일에 간섭하기 (잎사귀도 일종의 대상)
- 무대: 비자림 (자연 배경 — 공식 배경 목록에 없어 담당자 확인 필요. 기존 설정과 직접 충돌하는 요소는 없음)
- 기억상실 과거 언급 금지

## 8. 비고

- 부라봉의 "탐스러운 것"을 좋아하는 성향을 잎사귀에 적용 — 공식 설정과 연결
- 단일 캐릭터 + 자연 배경으로 구성
