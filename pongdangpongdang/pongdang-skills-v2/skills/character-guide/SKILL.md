- 우선순위: **공식 PDF/페이지 PNG > 구조화 가이드 > 사용자 입력 > AI 생성 결과**. 충돌 시 공식 원본을 우선한다.

## 2. 세계관

### 2.1 도입 서사 `[공식]`

> **'패밀리 콜렉터 부라봉?'**
> 제주 돌하르방 **'고르방'의 집**에는 어딘가 이상한 녀석들이 하나둘 모여든다.
> 그 시작은 **주문한 한라봉 박스에 같이 들어온 기억상실 사고뭉치 '부라봉'!**
> 갈 곳 없는 부라봉을 거두어 살게 된 고르방.
> 부라봉은 금세 집에 적응하더니, 자신과 비슷한 처지의 친구들까지 데려오기 시작한다!
> 그렇게 이들은 서로 다르지만 함께 살아가며, 어느덧 서로의 빈틈을 채워주는 진짜 가족이 되어간다.

### 2.2 무대 `[공식]`

- **주 무대는 '고르방의 집'이다.** (귤 농장이 아님 — 자주 발생하는 오류)
- 귤 농장(귤밭)은 **구애구가 지키는 '할머니의 귤밭'** 으로, 고르방의 집과 구분되는 별도 장소다.
- 배경 소재: 제주, 고르방의 집, 할머니의 귤밭, 바다, 자연

### 2.3 합류 경위 `[공식]`

| 캐릭터 | 합류 경위 |
|---|---|
| 부라봉 | 고르방이 **주문한 한라봉 박스에 같이 들어옴**. **기억상실** 상태. 갈 곳 없어 고르방이 거둠 |
| 양퐁당 | 부라봉이 **바다에서 구한 취준생** |
| 호꼬 | 부라봉이 **길에서 발견한 상처 입은 아기 백록** |
| 냥냥이 | 길을 가다 **부라봉을 간택한 길고양이** |
| 구애구 | 부라봉이 **귤을 훔치다 마주친** 농장 지킴이 강아지 |

### 2.4 세계관 운영 규칙

- `[운영]` 캐릭터 일상, 관계, 감정, 작은 사건을 중심으로 구성한다.
- `[운영]` 직접적인 상품 판매보다 세계관과 팬덤 형성을 우선한다.
- `[운영]` 기존 가족관계와 성격을 임의로 바꾸지 않는다.
- `[운영]` 공식 설정에 없는 나이, 직업, 과거, 혈연관계를 사실처럼 확정하지 않는다.
  - 특히 **부라봉은 기억상실 설정이므로 과거를 확정하는 서술을 금지한다.** `[공식 근거 + 운영]`
- `[운영]` 새로운 일상 사건과 제주 배경은 기존 설정을 훼손하지 않는 범위에서 허용한다.
- `[운영]` 새로운 고정 캐릭터나 중대한 세계관 확장은 담당자 승인을 받아야 한다.

다중 캐릭터 장면에서는 반드시 이 신장 순서를 지킨다. 매뉴얼 p7의 키비례표 기준선(1~14)을 따른다.

### 3.2 공통 원칙

- `[공식]` 각 캐릭터의 공식 턴어라운드(정면·측면·후면·3/4)가 존재한다. 실루엣과 비율은 이를 따른다.
- `[공식]` 캐릭터별 고유 색상, 얼굴 무늬, 장식, 잎, 모자, 볼터치의 **위치와 방향**을 유지한다.
- `[공식]` **얼굴 비율 및 신체 비율 변경 금지** (구애구 페이지에 OK/NO 예시로 명시. 전 캐릭터에 준용)
- `[운영]` 캐릭터 간 특징을 서로 섞지 않는다.
- `[운영]` 장면이 바뀌어도 외형과 고유 특징이 동일해야 한다.
- `[운영]` 이미지 생성 시 공식 참고 이미지를 함께 제공하는 것을 원칙으로 한다.

### 3.3 변형 허용 범위 `[공식]`

| 허용 | 금지 |
|---|---|
| 표정(눈·입) — **각 캐릭터별 허용 형태 내에서만** | 얼굴/신체 비율 변경 |

### 4.1 부라봉 · BOO RABONG

**정체성** `[공식]`
- 모티브: **한라봉**

- 꿈: **우주최고의 명품 과일**이 되는 것
- 역할: 엉뚱한 상상력과 해맑음으로 문제를 일으키는 **사고뭉치 · 사건의 발단**

**프로필** `[공식]`

| 항목 | 내용 |
|---|---|
| MBTI | 활동가(ENFP-A) |
| 좋아하는 것 | 귤, 달달한 음식, 비타민음료, 친구들과 노는 것, 우주, **겨울** |

| 장점 | 긍정적이고 활기참, 주변을 상큼하게 만들어줌, **추위를 타지 않음** |

### 4.2 고르방 · GO LEBANG

**정체성** `[공식]`
- 모티브: **돌하르방**
- 역할: **집주인이자 가족을 거두는 어른.** 부라봉을 처음 거둔 인물
- 딱딱한 외형과는 다르게 마음만큼은 **푸딩처럼 말랑말랑**하고, 인자한 웃음이 매력 포인트
- **오래 살아 온 연륜으로 아는 것도 많고 돈도 많다. 그리고 말도 엄청 많다**
- **나이, 직업 모든 게 미스터리인 신비주의 캐릭터**
- 관계도상 포지션: 양퐁당의 **"소중한 물주이자 건물주"**, 구애구의 **"밥 잘주는 동네 할아버지"**

**프로필** `[공식]`

| 항목 | 내용 |
|---|---|
| MBTI | 선도자(ENFJ-A) |
| 좋아하는 것 | 부라봉, 한라봉, **유채꽃**, 친구들과 수다떨기 |
| 싫어하는 것 | 지저분한 것, 예의없는 행동 |
| 장점 | 듬직하고 너그러움, **외부충격에 의한 통증을 거의 느끼지 못함** |
| 단점 | **말이 너무 많음, 아재개그, 마상을 잘 입음, 꼰대임** |
| 취미 | **부라봉 덕질하기**, 책읽기, 청소하기 |
| 특기 | 요리하기, **돈벌기, 돈쓰기(친구들에게)** |
| 특징 | 겉은 돌처럼 딱딱, 속은 말랑말랑 감성넘침(**겉바속촉**) |

- `[공식]` 다만 **화법 패턴은 명시되어 있다**: 말이 매우 많고, 아재개그를 하며, 이야기가 끝나지 않는다.
- `[공식]` 공식 대사 예: "안녕 우리 퐁당패밀리 많이 사랑해줘! 우리 라봉이는 귀엽고 사랑스럽고…(생략) 우리 퐁당이는 아주 씩씩하고 해녀를…(생략) 아! 그리고 나는…(**길어서 생략**)"

### 5.1 극성 체계 `[공식]`

매뉴얼 p5는 관계를 **긍정 / 중립 / 부정** 3단계로 구분한다. **부정 관계도 공식 설정이므로 임의로 훈훈하게 미화하지 않는다.**

| A → B | 라벨 | 극성 |
|---|---|---|
| 양퐁당 → 고르방 | 소중한 물주이자 건물주 | 긍정 |
| 고르방 → 양퐁당 | 식구가 되어서 좋아~ | 긍정 |
| (양퐁당 ↔ 고르방) | 나이는 다른 것 같지만 친구처럼 지냄 | 긍정 |
| 부라봉 → 고르방 | 든든한 조력자 | 긍정 |
| 고르방 → 부라봉 | 아주아주 귀여워함 | 긍정 |
| 양퐁당 → 부라봉 | 사고뭉치지만 미워할 수 없음 | 긍정 |
| 부라봉 → 양퐁당 | 좋을땐 든든한 보디가드 / **나쁘면 세상 무서운 존재** | 긍정 + 중립 |
| 부라봉 → 호꼬 | 돌봐주고 싶음 · 단짝 | 긍정 |
| 호꼬 → 부라봉 | **이파리가 좋아** 함께 있으면 안정감 | 긍정 |
| 부라봉 → 냥냥이 | 소유욕, 집착, 남주긴 아깝고 가까이 있으면 귀찮은 존재 | 긍정 + 중립 |
| 냥냥이 → 부라봉 | 돌보고 있다고 생각하지만 **역으로 돌봄받고 있다** | 중립 |
| 부라봉 → 구애구 | 귤 부자 친해지자 | 중립 |
| 구애구 → 부라봉 | **귤 도둑이지만** 미워할 수 없어 | 긍정 |
| 고르방 → 구애구 | 친구의 손자니까 챙겨주자~ | 긍정 |
| 구애구 → 고르방 | 밥 잘주는 동네 할아버지 | 긍정 |
| 양퐁당 → 호꼬 | 나름 귀여워함 | 중립 |
| **호꼬 → 양퐁당** | **첫인상 폭망** | **부정** |
| **호꼬 → 냥냥이** | **부라봉을 뺏길까봐 질투** | **부정** |
| **냥냥이 → 호꼬** | **무서운 존재** | **부정** |
| 냥냥이 → 구애구 | 아무생각없음 | 중립 |
| **구애구 → 냥냥이** | **무서운 존재** | **부정** |

### 5.2 포지션 `[공식]`

- **어른 그룹**: 고르방, 양퐁당 (나이는 다른 것 같지만 친구처럼 지냄)
- **반려동물 포지션**: 호꼬, 냥냥이, 구애구
- **중심**: 부라봉 (모든 관계의 허브)

### 5.3 권장 조합 `[구조화]`

| 조합 | 톤 | 소재 |
|---|---|---|
| 부라봉 + 호꼬 | 긍정 코미디 | 이파리 노리기, 탐험, 뒹굴기, 단짝 |
| 부라봉 + 양퐁당 | 허풍 vs 팩폭 | 사고 수습, 돌직구 |
| 부라봉 + 냥냥이 | 소유욕 vs 무심 | 누가 누구를 돌보는가 |
| 부라봉 + 구애구 | 귤 도둑 vs 지킴이 | 귤밭, 오해와 화해 |
| 고르방 + 부라봉 | 덕질하는 어른 | 수다, 아재개그, 귀여워하기 |
| 고르방 + 양퐁당 | 건물주 vs 취준생 | 현실 개그, 밥 얻어먹기 |
| 고르방 + 구애구 | 할아버지 vs 손자뻘 | 밥, 돌봄 |
| **호꼬 + 냥냥이** | **질투 · 견제** | 부라봉을 둘러싼 신경전 (**부정 관계 유지**) |
| **호꼬 + 양퐁당** | **첫인상 폭망** | 어색함, 서서히 풀리는 관계 (**결말에서 급히 봉합하지 말 것**) |
| 냥냥이 + 구애구 | 무관심 vs 두려움 | 일방적 경계 |

### 5.4 관계 금지

- `[운영]` 기존 가족을 처음 보는 사이로 설정
- `[운영]` 공식 관계를 원수 관계로 변경
- `[운영]` **공식 부정 관계를 임의로 훈훈한 관계로 미화** (v2 신설 — 자주 발생하는 오류)
- `[운영]` 가족 구성원을 영구 추방하거나 버리는 결말
- `[운영]` 연애·결혼 관계로 임의 변경
- `[운영]` 설정에 없는 혈연관계 확정
- `[운영]` 캐릭터 핵심 성격을 서로 뒤바꿈

## 6. 콘텐츠 톤앤매너

### 권장 `[운영]`

- 따뜻한 일상 코미디
- 성격 차이에서 생기는 작은 갈등 (부정 관계를 활용해도 좋다)
- 짧고 이해하기 쉬운 상황
- 제주, 고르방의 집, 할머니의 귤밭, 자연, 가족, 먹거리, 놀이 소재
- 마지막에 웃음, 따뜻함 또는 작은 반전
- 1분 미만에 이해 가능한 단순한 사건

### 금지 `[운영]`

- 노골적인 구매 유도 / 가격·할인·주문·링크 클릭 중심의 대사
- 폭력, 혐오, 선정성, 정치·종교적 선동
- 위험 행동 모방을 부추기는 내용
- 타사 캐릭터와 상표의 무단 결합
- 제주 문화와 해녀 문화 비하
- 캐릭터 사망, 심각한 부상, 가족 해체를 가볍게 소비
- 할머니(구애구의 보호자)의 죽음을 가볍게 다루거나 개그 소재로 사용

## 8. 자동 검수 체크리스트

### 8.1 즉시 실패 항목 (하나라도 해당 시 실패)

- [ ] 양퐁당이 해녀로 소개되었거나 물질·잠수·수영 장면이 있는가
- [ ] 호꼬에게 대사가 부여되었는가
- [ ] 부라봉의 기억상실 이전 과거가 확정되었는가
- [ ] 공식 부정 관계가 긍정 관계로 뒤바뀌었는가
- [ ] 존재하지 않는 캐릭터명이 등장하는가
- [ ] 캐릭터 간 고유 특징이 혼합되었는가
- [ ] 얼굴 비율·신체 비율이 변경되었는가
- [ ] 임의로 생성한 공식 색상 HEX가 사용되었는가

### 8.2 일반 검수 항목

- [ ] 캐릭터 이름·영문 표기가 정확한가
- [ ] 어미가 공식 말투와 일치하는가 (§7 말투표 기준)
- [ ] 고유 무늬·장식의 **위치와 방향**이 유지되는가 (양퐁당 동백 우측, 냥냥이 반점 좌측)
- [ ] 냥냥이 꼬리 무늬가 전체 길이의 1/5인가
- [ ] 부라봉 눈이 정원이며 세로눈이 아닌가 / 윗입술이 갈매기(3자) 형태인가
- [ ] 고르방 모자가 뒤쪽으로 기울었고 손끝·발끝이 뭉툭한가
- [ ] 호꼬가 오래 서 있지 않는가 (앉기·네발이 기본)
- [ ] 구애구의 머리→등 무늬가 누락되지 않았는가
- [ ] 다중 캐릭터 장면에서 키 순서가 맞는가
- [ ] 무대가 고르방의 집 / 할머니의 귤밭으로 올바르게 구분되었는가
- [ ] 성격·행동이 공식 프로필과 일치하는가
- [ ] 금지 행동이 포함되지 않았는가
- [ ] 직접적인 판매·구매 유도 문구가 없는가
- [ ] 제주 문화와 해녀 문화를 존중하는가
- [ ] 영상 길이가 60초 미만인가
- [ ] 장면이 바뀌어도 외형이 일관적인가
- [ ] 불명확한 설정을 담당자 확인 없이 확정하지 않았는가
