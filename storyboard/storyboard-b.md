# 스토리보드 B — 부라봉, 잎사귀 착각 소동 (대조 강조형)

> 이 스토리보드는 Solar Pro 4가 텍스트 문안 단계까지만 작성한 초안이다. 캐릭터 가이드 적용·준수 판정은 포함하지 않으며, 채택 확정은 Claude Code 검토 전이므로 미채택으로 기록한다.
> 이미지 생성은 이 smoke test에서 금지하므로, 장면 설명은 문안/구도 중심으로만 적는다.

## 기본

- 안: B안(대조 강조형)
- 길이: 15초
- 비율: 9:16
- 캐릭터: 부라봉
- 감정: 즐거움 · 코믹
- 범위: 기획 문안까지만. 이미지·영상·외부 배포 없음.

## 장면별 문안

### 장면 1 — establishing + 잎 강조 (0:00~0:03)

- 내용: 마당에서 쉬는 부라봉, 머리 위 잎사귀를 의식적으로 한 번 보여줌.
- 구도: 세로 프레임에서 부라봉과 머리 위 잎을 같이 잡음.
- 표정: 편안함.
- 자막: 없음.
- 소리: 잔잔한 환경음.

### 장면 2 — 날아간 잎 먼저 보여주기 (0:03~0:06)

- 내용: 다른 잎사귀 하나가 바람에 멀리 날아가는 컷을 먼저 보여 착각 단서를 제공.
- 구도: 잎사귀 이동에 시선 유도, 부라봉은 배경에.
- 표정: (부라봉) 시선 이동.
- 자막(후보): "방금 내 잎…?"
- 소리: 바람.

### 장면 3 — 착각 확대 (0:06~0:09)

- 내용: 부라봉이 자기 머리 위가 허전하다고 느끼고 과장된 더듬기/당황.
- 구도: 부라봉 클로즈업, 코믹 확대.
- 표정: 당황, 코믹.
- 자막(후보): "아니, 저건?"
- 소리: 코믹 반응음.

### 장면 4 — 거울 확인 (0:09~0:12)

- 내용: 거울/반사면에서 확인, 멀쩡함을 깨달음.
- 구도: 거울이 보이는 구도로 반전 강조.
- 표정: 의아 → 안도.
- 자막(후보): "아, 그대로 있었네…"
- 소리: 확인 느낌.

### 장면 5 — 머쓱 마무리 (0:12~0:15)

- 내용: 머쓱한 웃음으로 끝.
- 구도: 표정 클로즈업.
- 표정: 머쓱한 웃음.
- 자막(후보): "머쓱…"
- 소리: 가벼운 웃음/바람 잔향.

## 안별 차별점

- B안은 '날아간 잎'과 '내 잎'의 대조를 먼저 보여 착각을 더 두드러지게 만드는 방향.
- 이미지 없이 문안/구도만 제공하며, 채택은 Claude Code 검토 전 미채택.
