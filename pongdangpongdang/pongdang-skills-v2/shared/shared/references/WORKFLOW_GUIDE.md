# 퐁당패밀리 캐릭터 작업 가이드

이 폴더는 새 캐릭터를 만드는 자료가 아니다. 기존 캐릭터를 사용하는 모든 워크플로에서 원본 가이드라인을 빠르고 정확하게 확인하기 위한 작업용 참조본이다.

## 최우선 원칙

1. 캐릭터 작업을 시작하기 전에 이 파일과 관련 캐릭터의 지정 페이지를 반드시 연다.
2. 기억이나 일반적인 캐릭터 스타일을 기준으로 그리지 않는다.
3. 실루엣, 신체 비율, 얼굴 요소의 위치·크기, 고유 소품, 색상, 앞·옆·뒤 형태를 임의로 바꾸지 않는다.
4. 턴어라운드 페이지를 기준으로 방향별 외형을 맞춘다.
5. 사용 규칙 페이지의 O/X 예시를 확인하고 금지된 변형을 적용하지 않는다.
6. 원본에 없는 의상, 표정, 자세, 소품이 필요하면 기존 특징을 훼손하지 않는 범위인지 먼저 판단한다. 판단이 불확실하면 제작 전에 사용자에게 확인한다.
7. 여러 캐릭터를 함께 배치할 때는 `page-07.png`의 키 비교와 `page-05.png`의 관계 설정을 확인한다.
8. PDF 텍스트 자동 추출은 한글 폰트 인코딩 때문에 깨질 수 있다. 규정 판단은 반드시 페이지 PNG 또는 원본 PDF의 실제 화면을 기준으로 한다.

## 작업 유형별 확인 순서

### 단일 캐릭터 이미지

1. 해당 캐릭터 소개 페이지
2. 해당 캐릭터 턴어라운드 페이지
3. 해당 캐릭터 사용 규칙 페이지
4. 결과물과 원본을 나란히 비교

### 단체 이미지 또는 영상

1. `page-03.png` 세계관
2. `page-05.png` 관계도
3. `page-07.png` 키 비교
4. 등장하는 모든 캐릭터의 소개·턴어라운드·사용 규칙

### 새로운 포즈·표정·의상

1. 기본 외형과 턴어라운드 확인
2. 사용 규칙의 금지 예시 확인
3. 고유 실루엣과 식별 요소가 유지되는지 확인
4. 원본에 근거가 없고 해석이 필요한 부분은 사용자 확인 후 진행

### 영상·애니메이션

1. 장면마다 방향별 턴어라운드 일치 여부 확인
2. 프레임 사이 얼굴 요소와 고유 소품의 크기·위치가 흔들리지 않는지 확인
3. 캐릭터 간 상대 크기와 관계 설정이 유지되는지 확인
4. 최종 렌더 전 대표 프레임을 원본 규칙 페이지와 비교

### 생성형 도구로 이미지·영상을 만들 때

텍스트 프롬프트만으로는 이 가이드를 지킬 수 없다. 아래 구조를 지켜야 준수가 성립한다.

1. 등장 캐릭터의 소개·턴어라운드·사용 규칙 PNG를 **레퍼런스 이미지로 첨부**한다. 첨부 없이 호출하지 않는다.
2. 외형 서술은 `../guides/character-guide.json`의 `image_generation.characters.<id>.lock_en`을 그대로 쓴다. 요약하거나 다시 쓰지 않는다.
3. 같은 블록의 `forbidden` 항목을 네거티브 프롬프트에 전부 넣는다.
4. 단체 컷은 `page-07` 키비례표를 함께 첨부하고 키 순서를 지킨다.
5. 생성 후 결과를 다시 열어 `forbidden`과 1:1로 대조한다. 위반이면 한 번에 한 가지만 고쳐 재생성한다.

절차 전체는 `higgsfield-prompt-builder` skill이 수행한다. 프롬프트를 손으로 쓰지 않는다.

## 납품 전 체크리스트

- [ ] 작업에 등장하는 모든 캐릭터의 3개 필수 페이지를 확인했다.
- [ ] 캐릭터 이름과 영문 표기를 원본대로 사용했다.
- [ ] 정면·측면·후면 형태가 턴어라운드와 일치한다.
- [ ] 얼굴 요소, 실루엣, 신체 비율, 고유 소품을 임의 변경하지 않았다.
- [ ] 단체 장면의 상대 크기가 키 비교표와 일치한다.
- [ ] 관계와 행동이 세계관·인물 관계도와 충돌하지 않는다.
- [ ] 사용 규칙의 X 사례와 같은 변형이 없다.
- [ ] 불확실한 부분을 추측으로 확정하지 않았다.
