# 콘텐츠 기획안

## 기본 정보

- 콘텐츠 제목: 한밤중 냉장고 습격 사건, 귤 세례를 맞다봉
- 한 줄 요약: 한밤중 출출해진 부라봉이 몰래 냉장고 문을 열었다가, 안에 쌓아뒀던 귤이 우르르 쏟아지며 온몸에 귤 세례를 맞는 코믹한 해프닝을 그린다.
- 제작 목적: 부라봉 단독 주인공 콘텐츠를 통해 사고뭉치 매력과 일상 개그 세계관을 확산한다.
- 예상 길이: 15초
- 장면 수: 3장면
- 화면 비율: 9:16
- 출력 해상도: 1080 × 1920
- 등장 캐릭터: 부라봉 (1인, 다른 캐릭터 등장 없음)
- 배경: 고르방의 집 부엌, 냉장고 앞 (구체적 촬영 구역·인테리어는 미지정 — 담당자 확인 필요. 원문의 '부라봉의 집'은 공식 명칭이 아니므로 공식 무대인 '고르방의 집'으로 정정함)
- 핵심 감정: 즐거움·코믹
- 콘텐츠 유형: 일상 해프닝 + 코믹 리액션
- 생성 도구: Higgsfield
- 오디오: 미지정 (담당자 확인 필요)

## 스토리 구성

### 시작

깊은 밤, 온 가족이 잠든 고르방의 집. 출출해진 부라봉이 살금살금 부엌으로 들어와 냉장고 문 앞에 선다.

### 전개

야식거리를 찾으려 조심스레 냉장고 문을 스르륵 열자, 안에 차곡차곡 쌓아뒀던 귤들이 균형을 잃고 우르르 쏟아지기 시작한다.

### 핵심 포인트 또는 반전

쏟아지는 귤 더미에 놀라 눈이 휘둥그레진 부라봉이 두 팔을 벌려 막아보려 하지만, 오히려 머리부터 귤 세례를 뒤집어쓰고 만다.

### 마무리

바닥에 데굴데굴 굴러다니는 귤들 사이에 파묻힌 부라봉이 겸연쩍은 표정으로 이파리를 긁적이며 장면이 끝난다.

## 장면 개요

1. **0–5초 — 훅:** 깊은 밤 부엌, 살금살금 냉장고 앞으로 다가가는 부라봉. 조심스레 문손잡이에 손을 뻗는다.
2. **5–10초 — 전개(사고 발생):** 냉장고 문을 열자 쌓여 있던 귤들이 우르르 쏟아지기 시작, 놀라 눈이 커지는 부라봉.
3. **10–15초 — 반전(핵심 포인트) 겸 마무리:** 귤 세례를 뒤집어쓰고 바닥에 굴러다니는 귤 더미에 파묻힌 채 겸연쩍게 웃는 코믹 리액션으로 끝난다.

## 제작 요소

- 주요 대사: 구체적 대사·자막 문구는 담당자가 제공하지 않아 미정이다. 다음 단계(시나리오 작성)에서 확정하며, 확정 시 부라봉 공식 어미(`~다봉`/`~라봉`/`~냐봉`/`~다봉봉`)를 반드시 따른다. (담당자 확인 필요)
- 주요 행동: 살금살금 부엌으로 들어가기 / 냉장고 문을 조심스레 열기 / 쏟아지는 귤에 놀라 팔 벌려 막으려다 실패하기 / 귤 더미에 파묻혀 겸연쩍게 웃기
- 필요한 배경: 고르방의 집 부엌, 냉장고가 있는 공간 (구체적 촬영 구역·조명(한밤중 분위기)은 미지정 — 담당자 확인 필요)
- 필요한 소품: 냉장고, 귤 다수(쌓여 있던 귤 더미) — 공식 소품 목록 미확보 항목이므로 구체적 형태·디자인은 담당자 확인 필요
- 효과음: 미지정 (담당자 확인 필요, 예: 냉장고 문 여는 소리, 귤 쏟아지는 소리 등은 시나리오 단계에서 후보로 검토)
- 배경음악 분위기: 미지정 (담당자 확인 필요)
- 화면 자막: 자막 문구는 미정이며 시나리오 단계에서 확정한다. 사용 시 화면 상단 또는 하단 안전 영역에 배치하고 부라봉의 얼굴·꼭지 이파리·볼을 가리지 않는다.
- Higgsfield 설정: 캐릭터 이미지 생성 시 부라봉 공식 레퍼런스 페이지(소개 p08, 턴어라운드 p09, 사용 규칙 p10)를 반드시 첨부하고 `image_generation.characters.boo-rabong.lock_en` 문자열을 변형 없이 그대로 사용한다. 15초·3장면 분량에 맞춰 장면별 이미지 생성 후 이미지-투-비디오 방식을 권장하며, `sound` 설정은 오디오 방침이 확정된 뒤 결정한다(현재 미지정).

## 비주얼 고정 규칙

- 부라봉은 주황 한라봉 몸체, 초록 꼭지와 이파리(좌우 위치 모두 허용), 양쪽 큰 진한 주황 볼, 흰색 하의를 유지한다.
- 기본 눈은 정원이며 세로눈을 사용하지 않고, 지정된 감정 변형(예: 놀람) 외에는 눈 크기를 임의로 키우거나 줄이지 않는다.
- 윗입술은 뒤집힌 갈매기(3자) 형태를 유지하고, 입 가운데가 뾰족해지지 않게 한다.
- 눈과 입의 상하 간격이 벌어지지 않게 하고, 1.5등신 비율을 유지한다.
- 옆모습에서 꼭지는 중심에서 살짝 뒤로 기운 형태를 유지한다.
- 장면마다 정면·측면·후면 형태가 공식 턴어라운드(p09)와 일치해야 한다.
- 공식 HEX 값은 미확보 상태이므로 임의의 색상 코드를 사용하지 않고 서술형 색상 지시만 사용한다.
- 이미지 안에 대사·자막·말풍선·로고·워터마크를 넣지 않는다.
- 공식 6인 외 캐릭터(고르방, 양퐁당, 냥냥이, 호꼬, 구애구 포함)를 등장시키지 않는다.

## 검수 항목

- 캐릭터 가이드 준수: 부라봉의 한라봉 모티브·사고뭉치 정체성과 공식 어미(`~다봉`/`~라봉`/`~냐봉`)를 반영했다. 기억상실 이전 과거는 사실로 확정하지 않았다. 등장 캐릭터를 부라봉 1인으로 제한했다.
- 세계관 가이드 준수: 배경을 공식 무대인 '고르방의 집'으로 정정해 사용했다. 다른 캐릭터가 등장하지 않아 공식 관계 극성(§5)을 훼손할 소지가 없다.
- 직접적 상업성 노출 여부: 없음
- 저작권 위험 요소: 배경음악·효과음 사용 여부가 미확정이므로 사용을 결정할 경우 저작권이 확인된 음원만 사용해야 한다.
- 담당자 확인 필요:
  1. 부엌·냉장고의 구체적 인테리어·촬영 구역
  2. 대사 및 화면 자막 문구
  3. 배경음악·효과음 사용 여부와 분위기
  4. 게시 예정 플랫폼
  5. 냉장고·귤 더미 소품의 구체적 형태·디자인(공식 소품 목록 미확보)
  위 항목은 모두 다음 단계(시나리오·스토리보드) 진행 전 확정이 필요하다.
- 예상 수정 사항: Higgsfield 생성 시 부라봉의 눈·입·이파리·볼 형태와 귤 세례를 맞는 동작의 신체 비율이 흔들릴 수 있으므로 장면별 대표 프레임 검수가 필요하다. 15초라는 짧은 러닝타임 특성상 3장면 각각의 길이(약 5초)가 실제 편집 시 다소 조정될 수 있다.
