# 시나리오

## 콘텐츠 정보

- 제목: 라봉이를 식혀라!
- 총 길이: 30초
- 화면 비율: 9:16
- 등장 캐릭터: 부라봉, 고르방
- 핵심 메시지: 길고 화려한 계획보다 곁에서 조용히 챙기는 행동이 더 시원하고 따뜻한 휴가를 만든다.
- 오디오: 없음. 대사와 상황은 화면 자막과 행동으로만 전달한다.

- 시간: 00:00~00:05
- 배경: 맑고 뜨거운 여름날의 제주 바다, 검은 현무암 해안
- 등장 캐릭터: 부라봉
- 행동: 부라봉이 강한 햇빛 아래 축 늘어진 채 한 손으로 얼굴에 바람을 보낸다. 머리의 초록 이파리도 힘없이 처진 듯한 자세를 취하되 형태와 크기는 공식 외형을 유지한다.
- 표정: 기본 정원 눈을 유지한 피곤한 눈과 뒤집힌 갈매기 형태의 처진 입
- 대사: "라봉이는 여름이 싫다봉…"
- 카메라: 세로 화면 정면 미디엄 클로즈업에서 천천히 확대
- 자막: "라봉이는 여름이 싫다봉…" / 화면 상단 중앙 안전 영역
- 효과음: 없음
- 장면 전환: 부라봉의 시선이 화면 밖 고르방 쪽으로 움직이는 연속 동작 컷

- 자막: "자, 라봉아. 내가 완벽한 여름휴가 계획을 준비했는데…" / 화면 하단 중앙 안전 영역

### 장면 3

- 배경: 같은 피서 자리, 햇빛이 비치는 아이스박스 주변

- 표정: 고르방은 즐겁고 수다스러운 표정, 부라봉은 정원 눈 크기를 유지한 채 눈꺼풀과 입의 허용 범위 안에서 지친 표정
