# 스토리보드 C — 부라봉, 잎사귀 착각 소동 (감성형/세계관확장형)

> 원본 초안: Timely Agent(Solar Pro 4) 텍스트 문안. Claude Code가 `character-guide` v1.1 및 공식 페이지 03·08·09·10을 확인하고 검토·수정했다.
> 수정 내역: 자막을 부라봉 공식 어미로 교체, 배경을 '고르방의 집 마당'으로 명시, 각 장면에 정지 이미지 프롬프트용 단일 샷 카메라를 확정(`storyboard/prompts/c1.txt`~`c5.txt`).
> 이미지·영상 생성은 이 단계에서 실행하지 않는다. 장면 설명은 문안·구도·프롬프트까지만 다룬다.

## 기본

- 안: C안(감성형/세계관확장형)
- 길이: 15초
- 비율: 9:16
- 캐릭터: 부라봉
- 감정: 즐거움 · 코믹 (감은 서정적으로, 핵심은 코믹)
- 배경: 고르방의 집 마당
- 범위: 기획 문안 + 프롬프트 조립까지. 이미지·영상 생성은 제작·비용 승인 전까지 없음.

## 장면별 문안

### 장면 1 — 정적인 establishing (0:00~0:03)

- 내용: 마당에서 느긋하게 쉬는 부라봉의 조용한 한 컷.
- 구도: 세로 프레임, 부드러운 배치.
- 정지 이미지 카메라: `medium shot` (→ `prompts/c1.txt`)
- 표정: 편안, 살짝 여유.
- 자막: 없음.
- 소리: 부드러운 환경음.

### 장면 2 — 바람과 잎 (0:03~0:06)

- 내용: 바람이 살짝 스치고 잎사귀 하나가 흘러감.
- 구도(영상용 참고): 잎사귀가 조용히 흘러가는 느낌.
- 정지 이미지 카메라: `wide shot` — 잎이 떠 있는 한 순간으로 고정 (→ `prompts/c2.txt`)
- 표정: 부라봉이 잠깐 반응, 살짝 아쉬움.
- 자막: "어… 내 잎 맞냐봉?"
- 소리: 부드러운 바람.

### 장면 3 — 짧은 실망 (0:06~0:09)

- 내용: 부라봉이 잠시 혼잣말하듯 작은 실망을 보임.
- 구도: 클로즈업, 표정 중심.
- 정지 이미지 카메라: `close-up` (→ `prompts/c3.txt`)
- 표정: 실망/당황의 코믹한 미묘함. (기본 눈 정원 유지, 세로눈 금지)
- 자막: "잎이 없어졌다봉…"
- 소리: 짧은 코믹 음.

### 장면 4 — 확인/안심 (0:09~0:12)

- 내용: 손거울/반사면에서 확인, 그대로임을 알고 안심.
- 구도: 거울/반사면이 보이는 구도.
- 정지 이미지 카메라: `medium shot` (→ `prompts/c4.txt`)
- 표정: 의아 → 안도.
- 자막: "다행이다봉, 그대로 있다봉."
- 소리: 부드러운 확인음.
- 담당자 확인 필요: 손거울/반사면 소품 형태 — 공식 소품 목록 미확보.

### 장면 5 — 가벼운 마무리 (0:12~0:15)

- 내용: 머쓱하게 웃으며 가볍게 마무리.
- 구도: 표정 클로즈업.
- 정지 이미지 카메라: `close-up` (→ `prompts/c5.txt`)
- 표정: 머쓱한 웃음.
- 자막: "머쓱하게 웃는다봉."
- 소리: 가벼운 웃음/바람 잔향.

## 안별 차별점

- C안은 코믹 핵심을 유지하되 톤을 조금 더 부드럽고 짧게 가져가며, 세계관/분위기를 조금 남기는 방향.
- 채택 상태: 조건부 채택. 담당자 확인 필요 항목 해소와 제작·비용 승인 전까지 유료 생성 없음.
