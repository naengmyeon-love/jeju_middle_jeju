# 콘텐츠 기획안

## 기본 정보

- 콘텐츠 제목: 한밤중 냉장고를 열었다봉
- 한 줄 요약: 한밤중 야식이 당긴 부라봉이 몰래 냉장고 문을 열었다가 안에 쌓아둔 귤이 우르르 쏟아져 귤 더미에 파묻히는 코믹 해프닝이다.
- 제작 목적: 부라봉 단독 콘텐츠로 사고뭉치·호기심 캐릭터성과 고르방의 집 일상 세계관을 확산한다.
- 예상 길이: 15초
- 장면 수: 3장면
- 화면 비율: 9:16
- 출력 해상도: 1080 × 1920
- 등장 캐릭터: 부라봉 (단독, 다른 공식 캐릭터 미등장)
- 배경: 고르방의 집 부엌, 한밤중 (공식 무대는 '고르방의 집' 하나이며 page-03 세계관에서 가족이 함께 사는 집으로 확인됨. 부엌의 구체적 인테리어는 미지정 — 담당자 확인 필요)
- 핵심 감정: 즐거움 · 코믹
- 콘텐츠 유형: 일상 해프닝 + 코믹 리액션
- 생성 도구: Higgsfield (이미지 `nano_banana_flash`, 어려운 컷 `nano_banana_pro`)
- 오디오: 미지정 (담당자 확인 필요)

## 스토리 구성

### 시작

모두가 잠든 깊은 밤, 야식이 당긴 부라봉이 어두운 부엌으로 살금살금 들어와 냉장고 앞에 선다.

### 전개

부라봉이 냉장고 문손잡이를 잡고 조심스럽게 문을 연다. 문이 열리는 순간 안쪽 냉기와 불빛이 부라봉의 얼굴을 비춘다.

### 핵심 포인트 또는 반전

냉장고 안에 차곡차곡 쌓아뒀던 귤이 균형을 잃고 부라봉 쪽으로 우르르 쏟아진다. 부라봉은 눈이 커진 채 팔을 벌려 막아보지만 그대로 귤 세례를 맞는다.

### 마무리

바닥 가득 굴러다니는 귤 더미에 파묻힌 부라봉이 머리에 귤을 얹은 채 눈을 감고 웃는다. 사고는 쳤지만 좋아하는 귤에 파묻혔으니 결국 즐겁다는 반전으로 끝난다.

## 장면 개요

| S1 | 0–5초 | 어두운 부엌, 냉장고 문손잡이로 손을 뻗는 부라봉 | 설렘 · 몰래 하는 긴장 |
| S2 | 5–10초 | 열린 냉장고에서 귤이 쏟아지고 부라봉이 놀라 눈이 커진다 | 놀람 · 사고 발생 |
| S3 | 10–15초 | 바닥 귤 더미에 파묻힌 채 눈 감고 웃는 부라봉 | 즐거움 · 코믹 마무리 |

## 제작 요소

- 주요 대사: 담당자가 대사를 지정하지 않았다. 시나리오 단계에서 부라봉 공식 어미(`~다봉`/`~라봉`/`~냐봉`/`~다봉봉`) 범위 내 최소 분량으로 확정하며, 확정 문구는 담당자 확인을 받는다.
- 주요 행동: 살금살금 부엌 진입 → 냉장고 문 열기 → 쏟아지는 귤에 놀라 팔 벌리기 → 귤 더미에 파묻혀 웃기
- 필요한 배경: 고르방의 집 부엌, 한밤중 실내 (구체 인테리어·조명 톤 미지정 — 담당자 확인 필요)
- 필요한 소품: 냉장고 1대, 쌓아둔 귤 다수 — 공식 소품 목록이 미확보 상태이므로 형태·디자인은 담당자 확인 필요
- 효과음: 미지정 (담당자 확인 필요. 후보는 시나리오 단계에서만 제시하고 확정하지 않는다)
- 배경음악 분위기: 미지정 (담당자 확인 필요)
- 화면 자막: 문구 미정. 사용 시 세로 안전 영역 안에 배치하고 부라봉의 눈·입·꼭지 이파리·볼을 가리지 않는다. 이미지에는 굽지 않고 편집 단계에서 얹는다.
- Higgsfield 설정: 장면 이미지 생성 시 부라봉 공식 페이지 PNG(p08 소개 · p09 턴어라운드 · p10 사용 규칙)를 레퍼런스로 반드시 첨부하고, 외형 서술은 `image_generation.characters.boo-rabong.lock_en` 문자열을 변형 없이 사용한다. 프롬프트는 `higgsfield-prompt-builder` 조립기로만 만든다.

## 비주얼 고정 규칙

- 부라봉: 주황 한라봉 몸체, 머리 위 초록 꼭지·이파리(좌우 위치 모두 허용), 큰 주황 볼 2개, 흰색 기저귀형 하의, 1.5등신.
- 기본 눈은 정원이며 세로눈을 쓰지 않는다. 놀람 표현은 p10 허용 범위(반짝이는 눈/울먹이는 눈/겁먹은 눈) 안에서만 변형한다.
- 윗입술은 뒤집힌 갈매기(3자) 형태를 유지하고 가운데가 뾰족해지지 않게 한다.
- 눈과 입의 상하 간격을 벌리지 않는다.
- 옆모습에서 꼭지는 중심에서 살짝 뒤로 기운다. 앞모습이 옆모습보다 옆으로 더 넓적하다.
- 공식 HEX 미확보이므로 색상 코드를 만들어 쓰지 않고 서술형 색상만 사용한다.
- 이미지 안에 글자·자막·말풍선·로고·워터마크를 넣지 않는다.
- 부라봉 '명품' 스티커는 상시 요소 여부가 미확정이므로 사용하지 않는다.
- 공식 6인 외 캐릭터를 등장시키지 않으며, 이번 편은 부라봉 1인만 등장한다.

## 검수 항목

- 캐릭터 가이드 준수: 부라봉의 공식 정체성(한라봉 모티브, 대책 없는 호기심, 사고뭉치)과 p08의 '좋아하는 것 = 귤'에 부합한다. 공식 어미만 사용하며 기억상실 이전 과거를 확정하지 않는다.
- 세계관 가이드 준수: 무대를 공식 무대인 고르방의 집으로 사용했고, 구애구가 지키는 할머니의 귤밭과 혼동하지 않았다. 냉장고 안 귤은 집에 보관된 귤이며 귤밭 절도 설정과 무관하다.
- 직접적 상업성 노출 여부: 없음
- 저작권 위험 요소: 배경음악·효과음 미확정. 사용을 결정할 경우 저작권이 확인된 음원만 쓴다.
- 담당자 확인 필요 항목:
  1. 부엌 인테리어·조명 톤과 냉장고 디자인
  2. 대사 및 화면 자막 문구 확정
  3. 배경음악·효과음 사용 여부
  4. 게시 예정 플랫폼
  5. 귤 더미 소품의 표현 수위(개수·산포 범위)
- 예상 수정 사항: 귤이 쏟아지는 동세와 팔 벌린 자세에서 1.5등신 비율과 눈·입 간격이 흔들릴 수 있다. 장면별 대표 프레임을 p10과 1:1 대조해야 한다.
