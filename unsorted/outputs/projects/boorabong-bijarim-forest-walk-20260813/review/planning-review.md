## 4. 발견한 위반 사항과 수정 내역

### [수정 완료] storyboard-b.md 장면 3 — 눈 크기 규칙 위반

- **원문**: "부라봉 표정 | 놀란 눈이 더 커짐...", 체크리스트 "동그랗게 (더 큼)"
- **위반 근거**: `image-generation-contract.json`(v1.2) `characters.boo-rabong.forbidden`의 "기본 눈을 정원보다 작거나 크게 그리기 (지정된 감정 변형 제외)". 공식 계약에서 눈이 커지는 허용 변형은 "반짝이는 눈 — 평소보다 살짝 큼"과 "울먹이는 눈 — 더 큼"(눈물 상황 전용) 두 가지뿐이다(p10 원본의 9종 감정 눈 목록에도 "놀람 전용 확대"는 없다). 이 장면은 눈물이 아닌 감탄·비교 상황이므로 "더 큼"을 쓸 근거가 없다.
- **부수 발견**: 같은 기획(`plan-b.md`) §7은 "눈: 평소 눈과 동일 사이즈"로 이미 올바르게 적었는데, 스토리보드 문안 단계에서 "더 큼"으로 이탈했다. 기획-스토리보드 간 표현 불일치였다.
- **수정**: "반짝이는 눈 (평소보다 살짝 큼)"으로 정정 (표·체크리스트 모두). `../storyboard/storyboard-b.md` 참고.

### [수정 완료] plan-a.md / plan-b.md / plan-c.md — 비자림 배경 승인 여부 서술

- **원문**: "무대: 비자림 (신규 장소이나 기존 설정 훼손 없음 — 자연 배경 허용 범위)" (A), "(자연 배경 — 세계관 확장 허용 범위)" (B), "(자연 배경 — 기존 설정 훼손 없음)" (C)
- **문제**: "허용 범위"라는 표현은 공식 원본(p03 기본 세계관)에 근거가 없는 자체 승인 서술이다. p03은 배경 확장을 명시적으로 허용하거나 금지하지 않으며, `character-guide.json`의 공식 배경 목록(고르방의 집, 구애구가 지키는 할머니의 귤밭)에도 비자림은 없다. 동일 소재를 다룬 선행 프로젝트 `boorabong-bijarim-forest-walk-20260811`, `-15s` 모두 이 배경을 "미승인/담당자 확인 필요" 상태로 유지했다. Timely Agent 초안이 이를 스스로 "허용"으로 단정한 것은 AGENTS.md의 "원본과 충돌하는 요청이나 불확실한 표현이 있으면 임의로 추측하지 말고 사용자에게 확인한다" 원칙과 어긋난다.
- **수정**: 세 기획안 모두 "공식 배경 목록에 없어 담당자 확인 필요"로 정정. **승인하지 않았다** — 이번 검수는 표현만 정정했을 뿐, 배경 사용 자체를 확정하지 않는다.
