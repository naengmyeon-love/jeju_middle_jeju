# 스토리보드 C — 부라봉, 잎사귀 착각 소동 (감성형/세계관확장형)

> 이 스토리보드는 Solar Pro 4가 텍스트 문안 단계까지만 작성한 초안이다. 캐릭터 가이드 적용·준수 판정은 포함하지 않으며, 채택 확정은 Claude Code 검토 전이므로 미채택으로 기록한다.
> 이미지 생성은 이 smoke test에서 금지하므로, 장면 설명은 문안/구도 중심으로만 적는다.

## 기본

- 안: C안(감성형/세계관확장형)
- 길이: 15초
- 비율: 9:16
- 캐릭터: 부라봉
- 감정: 즐거움 · 코믹 (감은 서정적으로, 핵심은 코믹)
- 범위: 기획 문안까지만. 이미지·영상·외부 배포 없음.

## 장면별 문안

### 장면 1 — 정적인 establishing (0:00~0:03)

- 내용: 마당에서 느긋하게 쉬는 부라봉의 조용한 한 컷.
- 구도: 세로 프레임, 부드러운 배치.
- 표정: 편안, 살짝 여유.
- 자막: 없음.
- 소리: 부드러운 환경음.

### 장면 2 — 바람과 잎 (0:03~0:06)

- 내용: 바람이 살짝 스치고 잎사귀 하나가 흘러감.
- 구도: 잎사귀가 조용히 흘러가는 느낌.
- 표정: 부라봉이 잠깐 반응, 살짝 아쉬움.
- 자막(후보): "내 잎…?"
- 소리: 부드러운 바람.

### 장면 3 — 짧은 실망 (0:06~0:09)

- 내용: 부라봉이 잠시 혼잣말하듯 작은 실망을 보임.
- 구도: 클로즈업, 표정 중심.
- 표정: 실망/당황의 코믹한 미묘함.
- 자막(후보): "어, 여기 없네?"
- 소리: 짧은 코믹 음.

### 장면 4 — 확인/안심 (0:09~0:12)

- 내용: 거울/반사면에서 확인, 그대로임을 알고 안심.
- 구도: 거울/반사면이 보이는 구도.
- 표정: 의아 → 안도.
- 자막(후보): "어, 여기 있네."
- 소리: 부드러운 확인음.

### 장면 5 — 가벼운 마무리 (0:12~0:15)

- 내용: 머쓱하게 웃으며 가볍게 마무리.
- 구도: 표정 클로즈업.
- 표정: 머쓱한 웃음.
- 자막(후보): "머쓱…"
- 소리: 가벼운 웃음/바람 잔향.

## 안별 차별점

- C안은 코믹 핵심을 유지하되 톤을 조금 더 부드럽고 짧게 가져가며, 세계관/분위기를 조금 남기는 방향.
- 이미지 없이 문안/구도만 제공하며, 채택은 Claude Code 검토 전 미채택.
