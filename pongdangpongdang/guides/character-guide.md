# 퐁당패밀리 구조화 운영 가이드 v2.3

## 문서 지위

이 문서는 담당자와 AI가 사용하는 구조화 운영 문서다. 공식 원본은
`../references/제주애퐁당 캐릭터 사용 매뉴얼.pdf`이며 충돌 시 공식 원본이 우선한다.
캐릭터 결과물을 만들거나 검수할 때는 `../캐릭터_가이드라인_작업용/WORKFLOW_GUIDE.md`와
관련 페이지 PNG를 실제로 확인한다.

우선순위:

1. 공식 PDF와 동일한 페이지 PNG
2. 이 문서와 `character-guide.json`
3. 사용자 입력
4. AI 생성 결과

## 공통 규칙

- 공식 구성원: 부라봉, 고르방, 양퐁당, 냥냥이, 호꼬, 구애구
- 키 순서: 고르방 > 양퐁당 > 부라봉 > 구애구 > 냥냥이 > 호꼬
- 캐릭터의 얼굴·신체 비율, 실루엣, 고유 장식과 무늬 방향을 임의로 바꾸지 않는다.
- 양퐁당의 동백은 우측, 냥냥이의 눈 반점은 좌측이며 좌우 반전하지 않는다.
- 양퐁당은 해녀가 아니라 해녀복을 입은 토끼 취준생이며 수영을 못한다.
- 호꼬는 말을 못하므로 음성 대사를 부여하지 않는다.
- 호꼬의 뿔은 그리지 않는다. 뿔이 나는 자리에 살짝 볼륨감만 표현한다. (p22)
- 호꼬의 입은 평상시 보이지 않고 먹을 때만 있는 것처럼 보인다. (p22)
- 부라봉은 기억상실이므로 과거를 사실처럼 확정하지 않는다.
- 고르방의 집과 구애구가 지키는 할머니의 귤밭을 구분한다.
- 공식 색상 HEX와 로고 세부 규정은 미확보다. 값을 임의로 만들지 않는다.
- 공식 관계의 극성을 바꾸거나 연애·혈연 관계를 새로 확정하지 않는다.
- 직접적인 구매 유도, 가격·할인·판매 문구와 저작권 미확인 자산을 사용하지 않는다.

## 관계의 부정 극성

- 호꼬 → 양퐁당: 첫인상 폭망
- 호꼬 → 냥냥이: 부라봉을 뺏길까 봐 질투
- 냥냥이 → 호꼬: 무서운 존재
- 구애구 → 냥냥이: 무서운 존재

부정 관계는 갈등이 완화되는 사건을 만들 수 있으나 공식 관계 자체가 이미 긍정 관계인 것처럼 바꾸지 않는다.

## 이미지·영상 생성 계약

생성 도구(Higgsfield 등)로 캐릭터를 그릴 때의 계약은 `character-guide.json`의
`image_generation` 블록이 원본이며, 실행 절차는 `higgsfield-prompt-builder` skill이 담당한다.
프롬프트를 직접 손으로 쓰지 않는다.

핵심 구조는 다음 다섯 가지다.

1. **레퍼런스 고정** — 등장 캐릭터의 소개·턴어라운드·사용 규칙 PNG를 반드시 레퍼런스 이미지로 첨부한다. 텍스트 프롬프트만으로 캐릭터를 생성하지 않는다.
2. **문장 잠금** — 캐릭터 외형 서술은 `image_generation.characters.<id>.lock_en`을 그대로 붙인다. 요약·의역하지 않고, 장면 설명에서 외형을 다시 서술하지 않는다.
3. **금지의 명시** — `forbidden` 항목을 NEGATIVE 블록에 빠짐없이 옮긴다.
4. **사전 게이트** — `preflight_gate`가 모두 충족되기 전에는 호출하지 않는다.
5. **사후 대조** — 결과를 다시 열어 `forbidden`과 1:1 대조하고, 위반 시 한 번에 한 가지만 수정해 재생성한다.

모델은 레퍼런스 구동 캐릭터 모델(`nano_banana_2`, 어려운 컷은 `nano_banana_pro`)을 쓴다.
Soul ID는 실사 인물 얼굴 전용이므로 퐁당패밀리 캐릭터에 사용하지 않는다.

## 확인 필요

- 공식 컬러 팔레트 HEX
- 로고 최소 크기·여백·변형 규정
- 고르방 영문 표기 — 원본 내 불일치: 소개 p11은 `GO LEBANG`, 사용 규칙 p13은 `GO LE BANG`
- 배경·소품 공식 목록
- 부라봉 '명품' 스티커가 상시 요소인지 여부 (p08 소개 일러스트에만 등장)
- 냥냥이 머리 위 귤 소품이 상시 요소인지 여부 (p07 일러스트에만 등장)

확인 필요 항목은 값을 채우지 말고 담당자에게 확인한다.

### v2.3에서 해소된 항목

- **구애구/애구 표기** — 정식 표기는 소개 p23의 `구애구 / GU AEGU`. p25의 `애구 / GUAEGU`는 약칭이다.
- **호꼬의 뿔 표현** — p22에 "뿔이 나는 자리라서 살짝 볼륨감이 있다"로 명시. 뿔은 그리지 않는다.
