# 콘텐츠 기획안

## 기본 정보

- 콘텐츠 제목: 라봉이도 이만큼 커지냐봉?
- 한 줄 요약: 더위를 피해 비자림 숲을 찾은 부라봉이 수백 년 된 비자나무를 보고 자기도 저렇게 커질 거라 기대했다가 "너는 나무가 아니라 과일"이라는 말에 시무룩해지지만, 고르방이 우주 최고 명품 과일이 될 거라며 응원해 다시 신이 난다.
- 제작 목적: 부라봉의 엉뚱한 기대와 고르방의 다정한 응원을 통해 퐁당패밀리의 가족 관계와 제주 자연 세계관을 확산한다.
- 예상 길이: 30초
- 장면 수: 5장면
- 화면 비율: 9:16
- 출력 해상도: 1080 × 1920
- 등장 캐릭터: 부라봉, 고르방
- 배경: 제주 비자림 숲길 (붉은 화산송이 산책로, 비자나무 군락)
- 핵심 감정: 시원함과 감탄, 엉뚱한 기대에서 오는 반전 유머, 지지받는 따뜻함
- 콘텐츠 유형: 일상 여행 + 반전 감성(잔잔한 코미디 요소 포함)
- 생성 도구: Higgsfield
- 오디오: 없음

## 스토리 구성

### 시작

여름 더위를 많이 타는 부라봉이 시원한 비자림 숲길로 신나게 뛰어 들어간다. 고르방은 뒤에서 여유롭게 따라 걸으며 숲을 둘러본다.

### 전개

고르방이 수백 년 된 비자나무들을 올려다보며 특유의 수다와 아재개그를 늘어놓는다. 부라봉은 고개를 한껏 젖혀 거대한 나무를 올려다보며 감탄한다.

### 핵심 포인트 또는 반전

부라봉이 자기 머리 위 이파리를 만지작거리며 "라봉이도 나중엔 이만큼 커지냐봉?"이라고 기대에 차 묻는다. 고르방이 웃으며 "라봉이는 나무가 아니라 과일이잖아"라고 답하자 부라봉이 시무룩해진다.

### 마무리

고르방이 "대신 우주 최고 명품 과일이 될 거잖아"라고 덧붙이자 부라봉의 표정이 활짝 펴진다. "지켜봐주라봉~!" 하며 둘이 나란히 숲길을 걸어가는 뒷모습으로 마무리한다.

## 장면 개요

1. **0–5초 — 훅:** 비자림 입구의 붉은 화산송이 산책로. 부라봉이 시원한 숲 공기에 신나 뛰어 들어간다. 자막 "여긴 완전 시원하다봉!"
2. **5–11초 — 전개:** 숲길 한가운데. 고르방이 비자나무를 올려다보며 아재개그를 던진다. 자막 "비자림엔 비자가 필요 없지~ 하하"
3. **11–18초 — 감탄:** 가장 굵은 비자나무 아래. 부라봉이 고개를 젖혀 올려다보며 눈을 반짝인다. 자막 없음 또는 최소 감탄사.
4. **18–24초 — 반전:** 부라봉이 자기 이파리를 만지며 기대에 차 묻고, 고르방의 대답에 시무룩해진다. 자막 "라봉이도 이만큼 커지냐봉?" / "라봉이는 나무가 아니라 과일이잖아~"
5. **24–30초 — 따뜻한 엔딩:** 고르방의 응원에 부라봉의 표정이 펴지고 둘이 나란히 숲길을 걸어간다. 자막 "대신 우주 최고 명품 과일이 될 거잖아." / "지켜봐주라봉~!"

## 제작 요소

- 주요 대사: 음성 없이 화면 자막으로만 표현한다.
  - 부라봉: "여긴 완전 시원하다봉!"
  - 고르방: "비자림엔 비자가 필요 없지~ 하하"
  - 부라봉: "라봉이도 이만큼 커지냐봉?"
  - 고르방: "라봉이는 나무가 아니라 과일이잖아~"
  - 고르방: "대신 우주 최고 명품 과일이 될 거잖아."
  - 부라봉: "지켜봐주라봉~!"
- 주요 행동: 부라봉이 숲으로 신나게 뛰어 들어간다. 고개를 젖혀 나무를 올려다본다. 자기 이파리를 만지작거린다. 시무룩해졌다가 다시 활짝 웃는다. 둘이 나란히 숲길을 걸어간다.
- 필요한 배경: 비자림 붉은 화산송이 산책로, 비자나무 군락, 나뭇잎 사이로 들어오는 햇빛
- 필요한 소품: 없음 (신규 소품 없이 공식 기본 외형만 사용한다)
- 효과음: 없음
- 배경음악 분위기: 사용하지 않음
- 화면 자막: 모든 서사를 자막으로 전달한다. 훅 자막은 화면 상단, 대사 자막은 화면 하단 중앙 안전 영역에 배치하며 캐릭터 얼굴·꼭지 이파리·모자 유채꽃을 가리지 않는다.
- Higgsfield 설정: `sound=off`. 장면별 이미지-투-비디오 방식 권장. 장면 1~5의 외형 일관성을 위해 공식 캐릭터 레퍼런스를 동일하게 유지한다.

## 비주얼 고정 규칙

- 고르방은 부라봉보다 크게 표현한다 (키 순서 §3.1).
- 부라봉은 주황 한라봉 몸체, 초록 꼭지와 잎, 양쪽 진한 주황 볼, 흰색 하의를 유지한다.
- 부라봉의 기본 눈은 정원이며 크기를 키우거나 줄이지 않고 세로눈을 사용하지 않는다. 윗입술은 뒤집힌 갈매기(3자) 형태를 유지한다.
- 부라봉의 눈과 입 상하 간격이 멀어지지 않게 한다. 1.5등신 비율을 유지한다.
- 부라봉의 꼭지는 옆에서 볼 때 중심에서 살짝 뒤쪽으로 기운다. 이파리 위치는 좌우 모두 허용된다.
- 고르방은 회색 돌하르방 몸체, 둥근 챙모자와 노란 유채꽃 장식, 볼륨감 있는 큰 코를 유지한다.
- 고르방의 모자는 옆에서 볼 때 뒤쪽으로 기울고, 귀는 중심에서 약간 뒤쪽에 위치하며, 눈썹끝은 둥글고 손끝·발끝은 뭉툭하다.
- 고르방의 안경은 일할 때만 착용하는 요소이므로 여행 장면에서는 사용하지 않는다.
- 장면마다 정면·측면·후면 형태가 공식 턴어라운드(09, 12)와 일치해야 한다.
- 공식 HEX 값은 미확보 상태이므로 임의의 색상 코드를 사용하지 않고 서술형 색상 지시만 사용한다.
- 이미지 안에 대사·자막·말풍선·로고·워터마크를 넣지 않는다.

## 검수 항목

- 캐릭터 가이드 준수: 부라봉의 호기심 많고 천진난만한 성격, 더위를 많이 타는 공식 단점, 우주 최고 명품 과일이 되겠다는 공식 꿈, 공식 어미(~다봉/~라봉/~냐봉)를 반영했다. 고르방의 수다·아재개그 화법과 부라봉을 아주 귀여워하는 공식 긍정 관계를 반영했으며 고정 어미를 창작하지 않았다.
- 세계관 가이드 준수: 비자림은 제주 세계관의 자연스러운 확장 배경이나 공식 배경 목록 미확보로 확인 필요 항목으로 표시했다. 부라봉은 고르방을 든든한 조력자로, 고르방은 부라봉을 아주 귀여워하는 공식 긍정 관계를 유지했다.
- 직접적 상업성 노출 여부: 없음
- 저작권 위험 요소: 음원·음성은 사용하지 않는다. 자막 폰트는 사용권이 확인된 폰트만 사용해야 한다. 비자림의 실제 안내판·표지판·시설물은 사실적으로 재현하지 않는다.
- 담당자 확인 필요: 비자림 배경의 사용 허용 범위를 영상 생성 전에 확인한다. 실제 천연기념물 지정 구역의 특정 나무를 식별 가능한 형태로 묘사하지 않는다.
- 예상 수정 사항: Higgsfield 생성 시 부라봉의 눈·입·이파리·볼 형태와 고르방의 모자 기울기·유채꽃·코 볼륨·손발 형태가 흔들릴 수 있으므로 장면별 대표 프레임 검수가 필요하다.
